# 클라우드 포맷 — 한 장짜리

2026-10-09 주인 지시 — 「**클라우드 사이트는 포맷을 시켜도
상관없다.**」 루트를 통째로 비우고 새로 시작합니다.

---

# ⚠️ 비우기 전에 — **폴더를 반드시 확인하십시오**

**`badagaja.com` 과 `badagaja.cloud` 가 같은 서버입니다.
폴더를 잘못 고르면 바다가자닷컴 450쪽이 사라집니다.**

파일질라에서 폴더를 연 뒤, **눈으로 아래를 보고 가르십시오.**

### ✅ 비울 폴더 (cloud) — 이것들이 보입니다

```
    join.php          ← 이 파일이 있으면 cloud 입니다
    rules.html
    privacy.html
    css/club.css
    img/hero.jpg
```

### 🛑 비우면 안 되는 폴더 (badagaja.com) — 이것들이 보입니다

```
    point/            ← 이 폴더가 보이면 **즉시 멈추십시오**
    festival/
    fish/
    build.json
    assets/
```

> **한 줄 요약**
> `join.php` 가 보이면 **비웁니다.**
> `point/` 이나 `build.json` 이 보이면 **잘못 들어왔습니다 —
> 아무것도 건드리지 말고 나가십시오.**

---

## 1. 백업 — 한 번

파일질라에서 **cloud 루트 폴더를 통째로** 내려받습니다.

```
받을 곳:  G:\바다가자-백업\2026-10-09-cloud동호회\서버루트\
```

받고 나서 그 안에 `join.php` 가 있는지만 보시면 **맞게 받은 것**입니다.

---

## 2. 루트를 비웁니다

cloud 루트의 **모든 파일과 폴더**를 지웁니다.

```
    index.html · join.php · rules.html · privacy.html
    css/ · img/ · data/ · marketing/
    favicon.svg · robots.txt · sitemap.xml
    (그 밖에 보이는 것 전부)
```

> `marketing/` 도 **서버에서는 지웁니다.** 작업판 넷은
> 내 컴퓨터(`badagaja-site/cloud/marketing/`)에 그대로 있습니다.
> (재 보니 서버에는 원래 없었습니다 — 보이면 지우시면 됩니다)

---

받을 곳:  cloud 루트

## 4. 확인 — 네 줄

```
https://badagaja.cloud/              → 200 · 「오픈 준비 중」 · 가입 폼 없음
https://badagaja.cloud/join.php      → 404
https://badagaja.cloud/rules.html    → 404

https://badagaja.com/                → 200  ★ 이것도 꼭 보십시오
```

**마지막 줄이 중요합니다.** 바다가자닷컴이 멀쩡한지 확인하는
줄입니다. 만약 404 라면 **잘못된 폴더를 비운 것**이니
곧바로 알려 주십시오 — 되돌리겠습니다.

---

## 잘못되면

백업에서 루트를 통째로 되돌립니다.
`G:\바다가자-백업\2026-10-09-cloud동호회\서버루트\`

바다가자닷컴을 잘못 비웠다면 **다시 배포하면 됩니다** —
깃허브 액션 「운영 배포」를 돌리면 450쪽이 되살아납니다.
(이것이 우리에게 든든한 점입니다. cloud 는 그런 장치가
없으니 백업이 유일한 길입니다)

---

## 5. ★ 그다음 — `badagaja.com/club.html` (순서가 있습니다)

```
①  cloud 정리  (위 1~4)
②  /club.html 처리          ← 반드시 이 차례로
```

`badagaja.com/club.html` 의 **149~152줄**이 아직
`badagaja.cloud` 로 「동호회 신청하러 가기」를 보냅니다.
「창립회원을 모집하고 있습니다」라고도 적혀 있습니다.

**cloud 를 비우면 그 링크가 빈 쪽으로 갑니다.** 그래서 ①을
먼저 하고 ②를 합니다. 거꾸로 하면 cloud 가 아직 모집 쪽인 채
링크만 바뀌어, 두 사이트가 다른 말을 하는 상태가 길어집니다.

고치는 법은 **`.htaccess` 에 한 줄**입니다.

```apache
Redirect 301 /club.html /club/support.html
```

다만 `.htaccess` 는 **주인 규칙 27**(한 번에 하나씩 · 올린 뒤
응답 코드 확인 · BOM 금지)이 걸려 **따로 올려야 합니다.**
차례와 확인 줄은 `docs/club-html-변경안.md` 에 적었습니다.

**감독팀·지피티 모두 「비배포 범위」로 보류했습니다** —
주인이 「이것만 올려라」 하실 때 하겠습니다.
