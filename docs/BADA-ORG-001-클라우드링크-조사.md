# BADA-ORG-001 — badagaja.cloud 동호회 링크 전수 조사

2026-10-09 · 감독팀 지시.

> 「동호회는 badagaja.com 내부(실행팀 소관)에서 운영,
>  badagaja.cloud(광고팀)에는 동호회 기능을 새로 만들지 말 것.
>  **기존 cloud 쪽 동호회 링크가 남았는지 전수 조사 후 변경
>  목록만 감독팀에 보고(삭제·배포 금지).**」

**아무것도 지우지 않았고 아무것도 올리지 않았습니다.** 세기만 했습니다.

---

## 결론 먼저

| 어디 | cloud 링크 | 상태 |
|---|---|---|
| **새 판 450쪽** (`site/`) | **0** | ✓ 깨끗합니다 |
| 새 판 자료·생성기 | **0** | ✓ (「클라우드」라는 말은 깃허브 액션 주석뿐) |
| **공개 서버 주요 쪽** | **0** | ✓ index·about·gear·data 모두 없음 |
| **공개 서버 `/club.html`** | **2군데** | ⚠️ **살아 있습니다 (200)** |
| 옛 저장소 `cloud/` 넷 | 여러 곳 | 서버에는 **404** (안 올라가 있음) |

**손볼 곳은 하나입니다 — 서버에 남아 있는 `/club.html`.**

---

## 1. 새 판은 깨끗합니다

쪽 450개·자료·생성기·틀을 모두 뒤졌습니다.

    site/**/*.html 에서 badagaja.cloud  →  0군데
    data/raw/**.json 에서              →  0군데
    engine/*.py · template/*.html 에서  →  0군데

`engine/` 에 나오는 「클라우드」는 **깃허브 액션**을 가리키는
주석입니다(「클라우드 판정」·「클라우드에서 안 돌립니다」).
badagaja.cloud 와 무관합니다.

동호회 카드는 이제 `club/support.html`(badagaja.com 안)로
갑니다. 2026-09-27 에 있던 「바다가자 클라우드로 링크걸어서」는
2026-10-09 주인 지시로 바뀌었습니다.

## 2. 서버에 남은 것 — `/club.html`

```
https://badagaja.com/club.html   →  200   ← 살아 있습니다
  안에 badagaja.cloud 링크 2군데
```

- **새 판이 만들지 않는 쪽**입니다 (`site/club.html` 없음)
- 옛 판(`badagaja-site/club.html`)이 올려 둔 것이 남아 있습니다
- 배포가 `--delete` 를 안 쓰므로 **안 지워지고 계속 남습니다**
- 새 판 450쪽 가운데 **이 쪽으로 들어가는 길은 0개**입니다
  (차림표·꼬리말·본문 어디에도 링크가 없습니다)

즉 **손님이 돌아다니다 닿지는 않지만, 주소를 직접 치거나
검색 결과에서 들어오면 보입니다.**

### 옛 `cloud/` 넷은 서버에 없습니다

```
/cloud/                     404
/cloud/join.html            404
/cloud/open.html            404
/cloud/club/badagaja.html   404
```

저장소(`badagaja-site/cloud/`)에만 있고 올라가지 않았습니다.
**손볼 것이 없습니다.**

---

## 3. 변경안 (보고만 · 실행 안 함)

감독팀·주인이 정하실 일입니다. 세 길을 적습니다.

| 길 | 무엇을 | 좋은 점 | 걸리는 점 |
|---|---|---|---|
| **ㄱ** | `/club.html` 을 `club/support.html` 로 **301 보냄** | 옛 링크·검색 결과가 새 쪽으로 이어집니다 | `.htaccess` 를 고쳐야 합니다 (주인 규칙 27 — 한 번에 하나씩·올린 뒤 응답 코드 확인) |
| **ㄴ** | `/club.html` 을 **지움** | 가장 깔끔합니다 | 검색 결과에서 404 가 납니다. 되돌리기 어렵습니다 |
| **ㄷ** | **그대로 둠** | 아무 위험 없음 | cloud 를 가리키는 쪽이 계속 살아 있습니다 |

**제 의견은 ㄱ(301)** 입니다. 옛 쪽이 가리키던 뜻(동호회)을
새 쪽이 그대로 이어받으니 손님이 헛걸음하지 않습니다.
다만 `.htaccess` 는 주인 규칙 27 이 걸려 있어
**주인 결정 없이 손대지 않습니다.**

### 참고 — 왜 지금까지 몰랐나

배포가 `--delete` 를 안 씁니다. **옛 판이 올려 둔 쪽은 새 판이
안 만들어도 서버에 그대로 남습니다.** `/club.html` 말고도
이런 쪽이 더 있을 수 있어, 전수로 세어 보는 것이 좋겠습니다.
그것도 주인 결정 사항으로 함께 올립니다.
