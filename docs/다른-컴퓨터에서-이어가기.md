# 다른 컴퓨터에서 이어가기

2026-10-02. **외장하드는 거의 필요 없습니다.** 대장은 깃허브입니다
(주인 규칙 15 — 「저장소에 없으면 없는 것입니다」).

## 1. 새 컴퓨터에서 할 일

### ① 파이썬 3.12
<https://www.python.org/downloads/> — 설치할 때 **「Add Python to PATH」**
를 꼭 켭니다.

### ② 저장소 가져오기

```
git clone https://github.com/ohjunhan-design/badagaja-engine.git 두번째도전
cd 두번째도전
```

비공개 저장소라 깃허브 로그인을 묻습니다. 토큰이나 SSH 키가 없으면
깃허브 웹에서 **Settings → Developer settings → Personal access
tokens** 로 하나 만들어 비밀번호 자리에 넣습니다.

### ③ 사이트 짓기

```
python engine/build.py
```

`site/` 는 저장소에 없습니다 — **생성물이라 안 올립니다.**
자료에서 다시 지으면 똑같이 나옵니다(계약-07 멱등성).
448쪽이 3~4분이면 지어집니다.

### ④ 클로드 코드

<https://claude.ai/code> 에서 설치하고 로그인합니다. 작업 폴더를
`두번째도전` 으로 엽니다. `CLAUDE.md` 를 저절로 읽으므로 **규칙은
따로 알려 주지 않아도 됩니다.**

## 2. 저장소에 **없는** 것 — 이것만 옮깁니다

| 무엇 | 어디 | 크기 | 꼭 필요한가 |
|---|---|---|---|
| 클로드 기억 | `C:\Users\USER\.claude\projects\D-------badagaja-site\memory\` | 96KB | **예** — 겪은 일이 다 여기 있습니다 |
| 조사 자료 | `data-private\` 중 `지식백과`·`지식백과-그림`·`샷`·`gpt-log`·`뽑은채비.json` | 138MB | 아니오 — 없어도 사이트는 지어집니다 |
| 깃허브 열쇠 | `C:\Users\USER\.ssh\` | 작음 | 아니오 — **새로 만드는 편이 안전합니다** |

**비밀키(`.ssh`)는 외장하드에 복사하지 않기를 권합니다.** 외장하드를
잃으면 저장소를 통째로 내줍니다. 새 컴퓨터에서 새 열쇠를 만들거나
토큰을 쓰십시오.

기억 폴더는 새 컴퓨터의 같은 자리에 넣습니다. 폴더 이름은 작업
폴더 경로에서 나오므로, 작업 폴더를 다른 자리에 두면 이름이
달라집니다. 그때는 클로드에게 「기억 파일을 여기 두었다」고 말하면
됩니다.

## 3. 외장하드에 넣을 꾸러미

`G:\★바다가자-이어가기\` 에 둡니다 (2026-10-02 만듦).

```
G:\★바다가자-이어가기\
    memory\              클로드 기억 49개
    data-private\        조사 자료 (저장소에 없는 것만)
    이어가기.md           이 안내문
```

넣은 뒤 **반드시 대조합니다.** 외장하드는 조용히 끊깁니다 —
복사가 끝난 듯 보여도 파일이 모자랄 수 있습니다.

## 4. 판정과 배포는 컴퓨터와 상관없습니다

2026-10-02 에 깃허브 우분투로 되돌렸습니다
(`RUNNER_LABEL = ubuntu-latest`). 그래서

- 어느 컴퓨터에서 커밋해도 **판정이 저절로 돕니다** (12~13분)
- 주인 컴퓨터가 꺼져 있어도 돕니다
- 배포는 Actions → `deploy` → **「배포합니다」** 입력

전에는 주인 컴퓨터에 붙여 둔 일꾼으로만 돌아서, 재부팅하면
워크플로가 줄만 서고 **한 번도 안 돌았습니다.** 지금은 아닙니다.

## 5. 먼저 돌려 볼 것

```

python engine/check_photo_dup.py --strict
```

판정 전체(`./check full`)는 12~13분 걸리니 배포 직전에만 돌립니다
(기억 — 「판정 full 은 배포 직전만」).
