# 지피티와 합의한 것

바깥 검수(챗지피티)와 주고받으며 정한 것을 한곳에 적습니다.
**여기에 없으면 합의한 것이 아닙니다.** 창을 닫으면 대화는 사라지지만
이 파일은 남습니다.

- 대화 **원문**은 `data-private/gpt-log/` 와 `G:\대화내용\` 에 날짜별로 둡니다
- 이 파일에는 **결정만** 적습니다 (수십 쪽을 다시 읽지 않아도 되게)
- 글을 보낼 때 첫 줄에 **판 지문 한 줄**을 적습니다.
  서로 다르면 **이야기 전에 판부터 맞춥니다.**

기준판 — `바다가자 판 7001a99 · 2026-10-01 · 434쪽 · 886파일 · 8c619181`

**상태** — 제안 · 합의 · 구현중 · 완료 · 보류 · 폐기
(**합의와 구현완료는 다릅니다.** 합의했다고 된 것이 아닙니다)

**번호** — A 일하는 방법 · R 규정(금어기) · P 포인트 · D 디자인·그림 · C 검사
