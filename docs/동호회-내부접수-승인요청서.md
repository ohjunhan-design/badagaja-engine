즉 **지금은 아무것도 못 받는 상태**입니다. 아래 표의 「지금 방식의

| 메일로 받던 때의 흠 | 왜 뺐나 |
|---|---|
| 메일앱이 없으면 **아무 일도 안 일어남** | 휴대폰 웹브라우저에서 흔합니다 |
| 메일앱이 열려도 **거기서 그만둠** | 쓰던 흐름이 끊깁니다 |
| 주소가 쪽에 드러나 **수집 로봇의 밥** | 스팸이 늡니다 |
| 무엇을 적을지 **손님이 알아서** | 빠뜨린 채로 옵니다 |

### 그래서 지금 급한 것은 **받을 곳을 만드는 일**입니다

쪽에는 「열리면 이 자리에 바로 알려 드립니다」라고 **약속해 두었습니다.**
그 약속이 오래 비어 있으면 그것대로 흠입니다.

## 1. 무엇을 만드나

쪽에 있는 폼이 **우리 서버로** 보내고, 서버는 그것을
**파일 하나에 덧붙이고** 끝냅니다. 그게 전부입니다.

```
data/raw/site.json 의 `받는곳`
        │  빈 문자열이면 → 「준비 중」 안내 (★ 지금 이 상태)
        │  주소를 적으면 → 폼이 다시 생깁니다
        ▼
/club/support.html  (쪽은 이미 있음. 폼은 생성기가 만듭니다)
        │  폼 보내기
        ▼
api/club-apply.php   ← **새로 만들 것, 약 80줄로 봅니다**
        │
        ├ 받은 값을 **골라 담습니다** (화이트리스트)
        ├ 파일 잠금 뒤 덧붙입니다
        └ 「접수됐습니다」 쪽으로 보냅니다

data-private/club/2026-10.jsonl   ← **웹에서 못 읽는 자리**
```

**새로 만드는 쪽은 없습니다.** 폼은 `engine/build.py` 의
`_동호회신청폼()` 이 만들고, 그 함수는 `받는곳` 이 비었는지로
갈라 씁니다. 즉 **쪽을 손대지 않고 자료 한 줄로 열고 닫습니다.**

## 2. 작업 전후

| | 메일로 받던 때 | **지금 (운영 실측)** | 열면 |
|---|---|---|---|
| 보내는 곳 | `mailto:ohjunhan@gmail.com` | **없음** | `api/club-apply.php` |
| 쪽에 메일 주소 | 드러남 | **안 드러남** | 안 드러남 |
| 손님이 보는 것 | 메일앱이 열림 | **「준비 중입니다」** | 「접수됐습니다」 |
| 자료가 가는 곳 | 메일함 | **아무 데도** | `data-private/club/YYYY-MM.jsonl` |
| 알림 | 메일로 저절로 | — | **없음** — 최종결정자가 파일을 봐야 합니다 |

가운데 칸이 **지금**입니다. 받는 곳이 없으니 손님이 문의를 남길
길도 없습니다. `data/raw/site.json` 의 `받는곳` 이 빈 문자열이고,
`engine/build.py` 의 `_동호회신청폼()` 이 그걸 보고 폼 대신 안내만 냅니다.

→ **여는 일은 자료 한 줄입니다.** `받는곳` 에 주소를 적으면 생성기가
폼을 다시 만듭니다. 서버 쪽(`api/club-apply.php`)만 서면 됩니다.

마지막 줄이 중요합니다. **알림을 메일로 보내려면** 서버에서 메일을
보내야 하는데, 그건 범위를 더 넓힙니다. 이번에는 **받아 두기만** 하고
알림은 넣지 않는 쪽을 권합니다.

## 3. 무엇을 담나 — **담을 것만 적습니다**

「이건 빼자」가 아니라 **「이것만 담자」**로 짭니다. 그래야 폼에
칸이 늘어도 새 자료가 저절로 새지 않습니다.

```
받은때 · 동호회이름 · 지역 · 사람수 · 하는것
연락 (손님이 적은 것 하나 — 메일 또는 전화)
하고싶은말
```

**안 담는 것** (받아도 버립니다)
· IP 주소 · User-Agent · 쿠키 · 세션 · 리퍼러
· 폼에 없던 칸 (누가 끼워 넣어도 버립니다)

## 5. 접근 통제

| 무엇 | 어떻게 |
|---|---|
| 웹에서 못 읽게 | `data-private/` 아래에 둡니다. 서버 설정으로 막힌 자리입니다 |
| 혹시 몰라 한 겹 더 | 파일 이름을 `.jsonl` 로 — 브라우저가 열어도 목록이 안 보입니다 |
| 누가 읽나 | **최종결정자만.** FTP 로 내려받아 봅니다 |
| 팀은 | **안 봅니다.** 저는 그 파일을 열지 않습니다 |
| 공개 쪽에 나가나 | **아니오.** 어떤 쪽도 이 파일을 읽지 않습니다 |

★ **확인 결과 — 「막혀 있다」가 아니라 「아직 없다」입니다**
(감독실이 읽기 전용으로 쟀습니다, 2026-10-12)

| 주소 | 응답 |
|---|---|
| `/data-private/` | **404** |
| `/club/` | **404** |
| `/2026-10.jsonl` | **404** |
| 루트 `.htaccess` | **403** |

폴더가 없어서 404 가 난 것이지, 막혀서가 아닙니다. **만드는
순간 열릴 수 있습니다.**

→ 그래서 차례를 못 박습니다. **먼저 막고 나중에 만듭니다.**

1. 폴더를 **웹 루트 밖**에 두거나, 루트 안이면 `.htaccess` 에
   `Deny` 를 **먼저** 넣습니다
2. 빈 파일을 하나 올려 **바깥에서 403 인지 눈으로 확인**합니다
3. **그 확인이 끝난 뒤에야** 접수를 켭니다

이 차례를 지키지 않으면 첫 접수부터 공개됩니다.
