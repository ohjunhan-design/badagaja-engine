## ① 로컬 원본과 서버 공개판의 차이

| 파일 | 서버 | 지문 대조 |
|---|---|---|
| `/` (index.html) | 200 | **✗ 다릅니다** |
| `/rules.html` | 200 | ✓ 같음 |
| `/privacy.html` | 200 | ✓ 같음 |
| `/css/club.css` | 200 | ✓ 같음 |
| `/join.php` | **303** | (안 불렀습니다 — 303 은 「보내기」 응답) |
| `/data/applications.csv` | **403** | 막혀 있습니다 ✓ |
| `/admin.php` | **404** | **서버에 없습니다** |

### index.html 의 차이 — **로컬이 더 많습니다**

로컬에만 있고 서버에 없는 것:

```html
<section class="section section--alt" id="notice" hidden>
  ... 「NOTICE」 · 모임 일정 표(날짜·물때·장소·안내) ...
```

즉 **로컬 쪽이 더 나중 판**입니다. 공지·모임 일정 칸을 만들었는데
**아직 안 올렸습니다.** (`hidden` 이라 올려도 안 보였을 것입니다)

### `admin.php` 가 서버에 없습니다

로컬에만 있는 22KB 짜리 관리자 쪽입니다. 비밀번호를 해시로
`data/admin.json` 에 두고, 5번 틀리면 잠그는 짜임입니다.
**안 올렸거나 지웠습니다.** 지금 서버에서는 가입자 명단을
웹으로 볼 길이 없습니다(FTP 로만).

## ② join.php 가 개인정보를 어디에 저장하나 (코드만 읽음)

```php
$dir  = __DIR__ . '/data';
$file = $dir . '/applications.csv';
...
fputcsv($fp, ['신청일시','이름','연락처','연령대','거주지역',
              '관심활동','경험','하고싶은말','IP']);
```

**받는 것 아홉 가지** — 신청일시 · **이름** · **연락처** ·
연령대 · 거주지역 · 관심활동 · 경험 · 하고싶은말 · **IP**

| 어디에 | 어떻게 |
|---|---|
| `club/data/applications.csv` | 한 줄씩 덧붙입니다 (`fopen 'a'` + `flock`) |
| 웹 접근 | **`data/.htaccess` 가 막습니다** (`Require all denied`) — 서버 403 과 맞습니다 ✓ |
| 알림 메일 | `@mail()` 로 보냅니다. 본문에 **연락처를 안 넣고** 「FTP의 www/data/applications.csv 에서 확인하세요」라고만 적습니다 ✓ |

**잘 되어 있는 점** — 자료를 웹 밖에 두고, 알림에 개인정보를
싣지 않습니다. 감독팀이 정식판에 권한 것(「저장 성공과 알림
성공 분리 · 알림에 연락처 넣지 말 것」)을 **이미 지키고
있습니다.**

**살펴야 할 점**
- `applications.csv` 에 **실제 가입자가 몇 명 들었는지 모릅니다.**
  403 이라 웹으로 못 보고, FTP 는 안 붙었습니다
- `IP` 를 받습니다 — 개인정보입니다. 보존 기간이 정해져 있는지
  `privacy.html` 을 봐야 합니다
- 폴더 권한이 `0705` 입니다 (`@mkdir($dir, 0705, true)`)

## ③ 새 판 「모집 마감」과 cloud 모집 쪽이 모순되나

**네, 모순됩니다.**

| 어디 | 무엇이라 적혀 있나 |
|---|---|
| **badagaja.com** (새 판) | 「전국 낚시·해루질 동호회 **지원**」 — 기존 동호회를 돕는다는 안내. 모집하지 않습니다 |
| 〃 자료의 `_지난것` | 「창립회원 모집 **마감되었습니다**」 (2026-10-08 주인 지시로 내림) |
| **badagaja.cloud** (지금 공개 중) | 「바다가자 동호회 **창립회원 모집**」 — **가입 폼이 살아 있습니다** |

손님이 badagaja.com 에서 「모집 안 함」을 보고, badagaja.cloud
에서 「모집 중 + 가입하세요」를 봅니다. **한 운영자의 두 사이트가
서로 다른 말을 하고 있습니다.**

그리고 지금 cloud 가입 폼으로 **새 가입자가 계속 들어올 수
있습니다.** 마감한 모집인데 받고 있는 셈입니다.

## 주인 결정이 필요한 것

1. **cloud 모집 쪽을 어떻게 할지** — 내릴지, 「마감」으로 바꿀지,
   badagaja.com 의 동호회 지원 쪽으로 보낼지
2. **`applications.csv` 에 든 가입자 자료** — 몇 명인지 확인하고,
   보존할지 폐기할지. FTP 가 필요해 제가 못 봅니다
3. `privacy.html` 에 적힌 **보존 기간**을 지키고 있는지
4. 로컬에만 있는 `admin.php`·공지 칸을 **올릴지 버릴지**

**제가 한 일은 읽기뿐입니다.** 가입 폼을 부르지 않았고(303 은
HEAD 응답일 뿐), FTP 에 붙지 않았으며, 아무것도 고치거나
지우지 않았습니다.
