## 재시동 뒤에 할 일

`재시동뒤.bat` 을 두 번 누르시면 됩니다. 알아서 돕니다.

```
1. 묵은 임시 파일 치우기
2. 쪽 416개 다시 만들기
3. 전체 판정 (10~15분)
4. 결과를 tests\out\판정결과.txt 에 남김
```

끝나면 클로드에게 **「판정 끝났어」**라고만 말씀하시면 읽습니다.

### 왜 재시동이 필요했나

```
메모리 전체 31.8GB · 쓸 수 있는 것 1.9GB
커밋 45.4GB / 한계 48.7GB
그런데 프로그램이 잡은 것은 12.3GB 뿐  ← 33GB 를 시스템이 쥐고 있음
C 남은 공간 0.1GB                      ← 가상 메모리를 못 늘림
```

판정을 돌리니 `MemoryError` 와 「페이징 파일이 너무 작아서」가 나면서
검사기 다섯이 넘어졌습니다. **쪽이 잘못된 것이 아니라 컴퓨터가 못
버틴 것**인데 판정표에는 FAIL 로 찍혔습니다.

C 드라이브 정리는 주인이 **월요일에** 하시기로 했습니다.
