# OG 그림 주문서 — 채비 쪽 18장

바다가자 판 7001a99 · 2026-10-01

## 왜 필요한가

지금 채비 쪽 **18쪽의 공유 그림이 모두 같은 파일**(`home-hero.jpg`)입니다.
카카오톡·페이스북에 어느 채비를 나눠도 똑같은 바다 사진이 뜹니다.
네이버·구글 가이드는 **쪽마다 다른 그림**을 요구합니다.

## 규격 — 두 가지를 다 주십시오

| | 크기 | 쓰는 곳 |
|---|---|---|
| PC·공유 기본 | **1200 × 630** | 카카오톡·페이스북·트위터·구글 |
| 네모꼴 보조 | **600 × 600** | 일부 메신저가 네모로 자릅니다 |

- 가로세로 비가 **3:1 을 넘으면 안 됩니다** (가이드)
- **150×150 보다 커야** 합니다 (가이드)
- 파일은 webp 또는 png 로 주십시오. 줄이는 일은 제가 합니다

## 틀 — 18장이 **한 식구로 보여야** 합니다

하나하나 따로 만들지 마시고 **틀을 먼저 정한 뒤** 18장을 같은 계열로
지어 주십시오 (합의 D-001). SNS 에 섞여 나와도 「바다가자 것이구나」가
보여야 합니다.

제안하는 짜임 (바꾸셔도 됩니다)

```
┌──────────────────────────────────────────────┐
│  왼쪽 55%                    오른쪽 45%       │
│                                              │
│  ■ 채비 이름 (크게)          [채비 그림 또는   │
│  한 줄 설명                   낚시 장면 사진]  │
│  대상어종 · 어종 · 어종                       │
│                                              │
│  바다가자 · badagaja.com                     │
└──────────────────────────────────────────────┘
```

**지켜 주실 것**

- 글자는 **가장자리에서 60px 안쪽**에 두십시오. 메신저가 가장자리를 자릅니다
- 채비 이름은 **80px 이상**. 휴대폰 미리보기에서 작게 뜹니다
- 어두운 바탕에 밝은 글씨가 잘 읽힙니다 (바다 사진 위라면)
- 바다가자 색 — 바다 남색 `#0b4f7a` · 모래 `#f4ead8` · 주황 `#e8762c`

## 파일 이름 — 이대로 주십시오

```
assets/og/rig/{아이디}.webp        1200×630
assets/og/rig/{아이디}-sq.webp     600×600
```

틀이 쪽 갈래와 아이디를 보고 **스스로 고르게** 만들겠습니다 (합의 D-004).
쪽마다 손으로 적지 않습니다 — 지금 18쪽이 어긋난 까닭이 바로 그것입니다.

## 틀리면 안 되는 것

- **채비 차례를 바꾸지 마십시오.** 위에서 아래로 묶는 차례가 곧 낚시 방법입니다
- 안내도가 이미 있는 채비는 **그 그림의 부품 모양을 따라** 주십시오.
  OG 와 쪽 안 그림이 다르면 보는 분이 헷갈립니다
- 바늘·봉돌의 **크기 비례**를 지켜 주십시오
- 사람 얼굴이 나오는 사진은 쓰지 않습니다 (주인 규칙 2)
- 물고기는 **살아 있는 모습**으로. 잡아 늘어놓은 사진은 쓰지 않습니다

## 먼저 한 장만 보여 주십시오

18장을 다 지으시기 전에 **한 장(`metal` 메탈지그)만** 먼저 주십시오.
그 한 장으로 틀을 맞춘 뒤 나머지를 지으면 다시 짓는 일이 없습니다.
