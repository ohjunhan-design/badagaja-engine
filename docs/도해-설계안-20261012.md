# 「어디에 서서 노리나」 도해 — 지금 상태와 고칠 길 (설계안)

감독실 지휘 2026-10-12 · 「승인 시안 없이 새 그림 제작 금지 → **설계안까지만**」

**그림은 한 장도 만들지 않았습니다.** 지금 있는 것을 재고, 어떻게
고칠지 적기만 합니다.

## 0. 먼저 — **되돌아간 것이 아닙니다**

감독실이 「회색 직사각형/동그라미/삼각형 옛 도식」을 지적하셨고,
그 말씀은 **맞습니다.** 다만 **회귀는 아닙니다.**

| 재어 본 것 | 결과 |
|---|---|
| 운영 `fish/ureok.html` vs 로컬 | **53,153바이트로 완전히 같음** |
| 옛 저장소 오전 판(`663063ec`)의 도해 | **지금과 글자 하나 다르지 않음** |
| git 에 더 나은 판이 있었나 | **없음** — `_자리그림_도형` 커밋 하나뿐 |

즉 **처음부터 이 모양이었습니다.** 2026-10-08 주인 지시로 만든
「일반 도해」가 맞습니다 —

> 주인 — 「서는자리 모래바닥 이런거 다 잘못되었어. 이렇게 하려면
>   빼는 게 더 좋아. 아니면 사진 이미지가 아닌 **일반 그림으로
>   그려주는 게 더 좋지.**」

사진 위에 점·선을 얹던 길을 끈 것(`art.py` 의 `사진위에얹을까 = False`)
도 같은 지시입니다. 관광 사진에 선을 얹으면 **그 사진의 실제 지형과
맞지 않는데 맞는 척**하게 되어 위험합니다.

**그러니 고칠 것은 「되돌리기」가 아니라 「품질 올리기」입니다.**

## 1. 지금 무엇이 있나 — 전수로 셌습니다

### 어종 18쪽 — 뼈대 **3가지**를 돌려씁니다

| 뼈대 | 쪽 수 | 어느 쪽 |
|---|---|---|
| 방파제 (`rect4 circle2 path7`) | **9쪽** | 붕장어·병어돔·참돔·도다리·돌돔·고등어·전어·주꾸미·노래미 |
| 갯바위 (`rect2 circle1 path5`) | **8쪽** | 볼락·감성돔·가오리·학공치·무늬오징어·농어·숭어·우럭 |
| 하구 (`rect3 circle1 path3`) | **1쪽** | 망둥어 |

글귀까지 넣으면 5가지입니다. 방파제 꼴은 가운데 한 줄만 바뀝니다
(「벽 모서리와 기둥 둘레」·「벽 아래 바닥을 끌어」·「바위와 모래가
만나는 자리」). **갯바위 8쪽은 글자까지 완전히 같습니다** —
「서는 자리 / 물살이 도는 쪽」뿐입니다.

### 단계 쪽 — 셋이 **같은 그림에 꼬리표만** 다릅니다

틀(`template/fishing-levels.html`)을 세어 보면 초급·중급·고급이
`fl-map` 3개 · `fl-sea` 3개 · `fl-mark m1/m2/m3` 각 3개 ·
`fl-arrow` 3개 — **구조가 똑같습니다.**

화면으로도 확인했습니다. 셋 다 **연한 녹색 비탈 + 갈색 바닥 +
주황 화살표**이고 알약 꼬리표 글자만 바뀝니다. 곶부리도, 수중여도,
물골도 **그려지지 않습니다.**

## 2. 승인된 기준이 **이미 있습니다**

`data/raw/fishing-levels.json` 의 `시각기준` 입니다
(2026-10-12 오전 커밋 `72386a5` 로 들어왔습니다).

| | 기준 |
|---|---|
| **공통** | 사진 질감의 **사선 조감도**(육지와 수면을 동시에 보는 30~45도 시점), 안전 발판과 목표 수역을 명확히 구분, 글자·범례는 HTML 오버레이 |
| 초급 | 평탄한 내항·항구·안전한 방파제 끝, 완만한 수면과 발판 |
| 중급 | 외항 방파제와 접근 가능한 낮은 바위 해안, 조류 경계와 수심 변화 |
| 고급 | 곶부리·수중여·물골·본류와 지류의 만남·와류, 퇴로와 위험 노출 분리 |

**지금 그림은 이 기준을 안 지킵니다.**

| 기준 | 지금 |
|---|---|
| 사선 조감도 30~45도 | **평면 비탈** — 위에서 본 것도 옆에서 본 것도 아님 |
| 안전 발판과 목표 수역 구분 | 갈색/녹색 두 덩이뿐, 발판이 어디인지 모름 |
| 단계마다 다른 지형 | **셋이 같은 그림** |
| 글자는 HTML 오버레이 | 이건 **지키고 있습니다**(알약 꼬리표) |

## 3. 고칠 길 — 셋 중 고르십시오

### ㉮ 지형을 실제로 다르게 그립니다 (기준에 가장 맞음)

단계·갈래마다 **다른 지형**을 그립니다. 지금 공유하는 뼈대를
버리고 갈래마다 제 모양을 갖습니다.

```
  초급·방파제   곧은 콘크리트 벽 + 테트라포드 + 안쪽/끝자락
  중급·외항     굽은 외항 모서리 + 홈통 입구 + 조류가 갈리는 선
  고급·곶부리   튀어나온 곶 + 물속 여(숨은 바위) + 물골 + 와류
  하구          강과 바다가 만나는 자리 + 섞이는 띠
```

| | |
|---|---|
| 좋은 점 | 기준을 지킵니다. 손님이 **자기 자리를 알아봅니다** |
| 드는 품 | 큼 — 그림 넷을 새로 그립니다 |
| ★ 막는 것 | **승인 시안이 없습니다.** 제가 그리면 「임의 제작」입니다 |
| 필요한 것 | 시안 넷 (지피티께 의뢰 → 주인 확정) |

### ㉯ 지금 뼈대를 두고 **알맹이만** 채웁니다

그림 틀은 그대로 두고, 기준이 말하는 것을 **표시로** 더합니다.

```
  지금        발판(갈색) + 물(녹색) + 화살표 + 꼬리표 2~3개
  더하면      + 수심이 바뀌는 선   (점선)
              + 퇴로              (화살표 반대쪽)
              + 위험 자리          (빗금)
              + 물속 여            (물 아래 흐린 덩이)
```

| | |
|---|---|
| 좋은 점 | 품이 적고, 시안 없이도 **기준의 절반은** 채웁니다 |
| 모자란 점 | 「사선 조감도」는 여전히 아닙니다. 지형도 여전히 같습니다 |
| 필요한 것 | 승인만 — 새 그림이 아니라 **있는 그림에 표시 더하기** |

### ㉰ 지금 그대로 둡니다

회귀가 아니고, 2026-10-08 주인 지시를 지키고 있으며, 「사진에 선을
얹어 틀린 정보를 확정적으로 보이는」 위험도 없습니다.

| | |
|---|---|
| 좋은 점 | 아무것도 안 깨집니다 |
| 모자란 점 | **18쪽이 세 가지를 돌려쓰는 것**은 그대로입니다. 어종을 바꿔 봐도 같은 그림이면 손님은 「대충 만든 쪽」으로 읽습니다 |

## 4. 제 생각

**㉯ 를 먼저, ㉮ 를 나중에** 권합니다.

㉮ 가 옳지만 시안이 있어야 하고, 시안을 받으려면 시간이 걸립니다.
그 사이 ㉯ 로 **지금 그림이 말해 주는 것을 늘릴 수** 있습니다 —
특히 **퇴로와 위험 자리**는 안전에 걸리는 것이라 먼저 보여 줄 값이
있습니다.

다만 ㉯ 도 **승인이 필요합니다.** 「있는 그림에 표시 더하기」이지만
결과적으로 그림이 달라지기 때문입니다.

### 어느 쪽이든 함께 할 것

**갯바위 8쪽이 글자까지 똑같은 것**은 따로 고칠 값이 있습니다.
어종마다 「어디서」 자료가 다른데 도해가 그걸 안 씁니다.
방파제 꼴은 이미 가운데 글귀를 어종마다 바꾸고 있으니,
**갯바위 꼴도 같은 방식으로** 한 줄 넣으면 됩니다 — 그림은 안 건드리고
글만 바꾸는 것이라 품이 작습니다.
