**저는 법제처 원문을 직접 보지 않았습니다.** 그래서 전부 「검토대기」이고,
제가 원문을 확인한 뒤에야 「확인됨」으로 올립니다. 짐작으로 법을 적지 않습니다.

네 갈래는 **초안 단계에만** 씁니다. 최종 `data/raw/rules/금어기.json` 에는
**확인된 사실과 근거만** 들어갑니다 (합의 R-015).

## ③ 근거없음 — 출처를 못 찾았습니다. 쪽에 내보내지 않습니다
