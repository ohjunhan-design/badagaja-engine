### ★ 0종인 둘을 어떻게 하나

**④ 곶부리·외곽 갯바위** — 어종 자료 어디에도 「곶부리·수중여·
물골·포말」이 안 적혀 있습니다. 단계 쪽 고급 칸에는 있지만
**어종별로는 근거가 없습니다.** 억지로 붙이면 없는 사실을
만드는 것입니다.
→ **쪽은 만들되 어종 연결은 비웁니다.** 자료가 생기면 저절로 붙습니다.

**⑧ 선상·깊은 수심** — **주인 규칙 10** 에 걸립니다.
> 낚시 포인트는 갯바위·항구에서 직접 하는 낚시 기준입니다.
> 배 타고 나가는 선상낚시 자료는 넣지 않습니다.
→ **만들지 않는 쪽을 권합니다.** 지시에는 「확장」으로 적혀 있으나
  규칙과 부딪힙니다. 판단을 받고 싶습니다.

## 3. 새 쪽 — `/guide/fishing-spots.html`

### 짜임 (짧은 스크롤 · 탭 고르기)

```
  머리띠 (450쪽 공용)
  ─────────────────────
  제목  어디서 낚시하나
  한 줄  장소마다 서는 자리와 노리는 법이 다릅니다
  ─────────────────────
  [내항] [외항] [낮은 갯바위] [곶부리] [모래] [하구] [여밭]
       ↑ 탭 — 누르면 아래가 바뀝니다 (스크롤 안 함)
  ─────────────────────
  ┌───────────────────┐
  │  장소 그림 (PC/모바일 갈라짐)  │   ← 슬롯 ①
  └───────────────────┘
  어디에 서나 / 어디를 노리나 / 먼저 볼 것   ← 카드 3
  ⚠ 안전                                  ← 늘 보임
  ─────────────────────
  여기서 나오는 것   [감성돔] [우럭] [볼락] …   ← 어종으로
  ─────────────────────
  아래 탭바 (공용)
```

| 항목 | 값 |
|---|---|
| 로컬 주소 | `site/guide/fishing-spots.html` |
| 생성기 | `engine/build.py` 갈래 `'장소유형'` (새로) |
| 틀 | `template/fishing-spots.html` (새로) |
| 자료 | `data/raw/fishing-spots.json` (새로) |
| 매핑 | 같은 자료 안에 어종 코드 목록 |
| 그림 슬롯 | `img/fishing-spots/{코드}-pc.webp` · `-mobile.webp` |

### 그림이 없을 때

**빈 네모를 두지 않습니다.** 그림이 없으면 그 자리를 **접고**
글 카드만 냅니다. 「준비 중」이라고 적지도 않습니다 — 손님에게는
없는 것이 그냥 없는 것이어야 합니다.
(겪은 일 — 「약속한 것이 거기 있어야」)

## 4. 어종 쪽은 어떻게 바뀌나

### 지금 (회색 도해)
```
  어디에 서서 노리나
  ┌──────────────┐
  │ [회색 도형]   │   ← 18쪽이 3가지를 돌려씀
  └──────────────┘
```

### 바꾼 뒤
```
  어디서 노리나
  [방파제 내항 →] [모래·사니질 →]    ← 자기 장소만, 누르면 그 쪽으로
  ⚠ 테트라포드 위험 (해당 어종만)
```

**회색 도해는 더 만들지 않습니다**(지시 C). 지우는 것이 아니라
**생성기가 안 내게** 합니다 — `art.자리그림()` 호출을 끊습니다.

### 지키는 것 (지시 C)
「좋은 시간」·채비·미끼·귀띔 등 **지금 있는 정보는 그대로** 둡니다.
장소 줄만 바꿉니다.
