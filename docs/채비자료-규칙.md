# 채비 자료를 만들 때 지키는 것

> **주인 지시 (2026-09-30)** — 「채비관련된건 매우 중요한 바다가자의 자산이야
> 채비관련 자료 만들때 규칙을 별도로 정리해서 보관해」

채비 자료는 **이 사이트가 가진 것 중 가장 값진 것**입니다.
포인트·물때는 공공자료에서 옵니다. 그러나 **채비도는 우리가 직접 조사해 그린 것**이고,
한 곳이라도 틀리면 **손님이 낚시점에서 엉뚱한 물건을 사게 됩니다.**

아래는 **일곱 번 틀리고 일곱 번 바로잡으며** 얻은 것입니다. 예외 없습니다.

---

## 1. 자료가 먼저, 그림은 나중

| | |
|---|---|
| 값이 사는 곳 | `data/raw/rigs.json` **한 곳** |
| 그림 그리는 곳 | `engine/art.py` 의 `_부품모양()` · `채비도()` |
| 쪽 만드는 곳 | `engine/build.py` 의 `채비쪽()` · `채비목록()` |

- **호수·길이·무게를 그림 코드에 박지 않습니다.** 자료에서 읽습니다 (주인 규칙 29).
- 갈래를 하나 더하면 **쪽이 저절로 생깁니다** (`만들목록()`이 자료를 봅니다).

## 2. 값은 낚시점 채비도에서 가져옵니다

- **호수·길이의 기준**은 **머털낚시**(`m.wfish.co.kr/page/v288……`)입니다.
  어종별로 낚싯대·릴·원줄·찌·수중찌·목줄·봉돌·바늘을 표로 정리해 둡니다.
- 규격표에 **없는 값은 비워 둡니다.** 그럴듯하게 채우지 않습니다.
  전유동 수중찌 호수가 그랬습니다 — 규격표에 없어서 값을 비우고 귀띔만 달았습니다.
- **요약 도구(WebFetch)의 결과를 그대로 믿지 않습니다.**
  막대찌 채비 순서를 물었더니 반달구슬과 맨도래 자리를 뒤바꿔 답했습니다.
  **순서가 걸린 것은 반드시 원문을 눈으로 봅니다.**

## 2-1. **한 곳만 보지 않습니다 — 그림으로 된 채비도를 함께 봅니다**

> **주인 지시 (2026-09-30)** — 「머털낚시만 보지말고 전체적인 그림이
> 나온것을 네이버 이미지로 검색해서 가장 설명이 좋은 그림을 기준으로
> 추가해줘」

낚시점 규격표는 **숫자는 정확하지만 그림이 없습니다.**
부품이 어떤 차례로 붙는지, 어떻게 생겼는지, 어느 쪽이 위인지는
**그림으로 된 채비도**를 봐야 압니다.

**그래서 이렇게 합니다.**

1. 낚시점에서 **호수와 길이**를 가져옵니다 (숫자의 기준).
2. **네이버 이미지**에서 그 채비 이름으로 찾아, **부품 이름이
   화살표로 달린 채비도** 여러 장을 봅니다.
3. 그중 **설명이 가장 또렷한 것**을 골라 **차례와 생김새의 기준**으로
   삼고, `_근거` 에 어디서 본 것인지 적습니다.
4. 여러 그림이 서로 다르면 **주인께 여쭙니다.** 혼자 정하지 않습니다.

**겪은 일** — 막대찌를 원줄에 꿰어 세워 그렸습니다. 낚시점 규격표에는
「막대찌 3B~5B」라고만 적혀 있어 알 수 없었습니다. 주인이 보내 주신
채비도와 실물 사진을 보고서야 **홀더 스냅에 한쪽만 걸려 옆으로
눕는다**는 것을 알았습니다.

**실물 사진이 가장 좋은 근거입니다.** 그림은 그린 사람의 해석이 섞이지만
사진은 있는 그대로입니다.

## 3. 부품은 **하나하나 쇼핑몰에서 제품을 찾아** 그립니다

이름만 보고 그리면 틀립니다. 실제로 이렇게 틀렸습니다.

| 부품 | 제가 그렸던 것 | 실제 제품 |
|---|---|---|
| **O형 쿠션고무** | 동그란 고리 (알파벳 O 를 보고) | **검고 작은 타원 알갱이** |
| **구멍찌** | 흰 몸통에 주황 윗부분 | **도토리꼴에 주황 몸통** |
| **반달구슬** | 동그란 구슬 | **반구** — 둥근 면이 위, 평평한 면이 아래 |
| **도래** | 가로로 눕힘 | **세로** — 원줄과 목줄을 위아래로 잇습니다 |
| **좁쌀봉돌** | 고리 달린 물방울꼴 | **고리 없음.** 홈에 목줄을 끼우고 눌러 뭅니다 |
| **찌멈춤고무** | (검은 쿠션고무로 그려질 뻔) | **작은 형광 원통** — 연두·주황·노랑 |

「O형」의 O 는 **생김새가 아니라 제품 갈래 이름**이었습니다.

**찾는 곳** — 머털낚시(m.wfish.co.kr) · gigskorea.com · ujft.co.kr ·
nssr.co.kr · mobys.co.kr · samwonfishing.co.kr

## 4. 파는 것과 쓰는 것은 다릅니다

- 낚시점은 O형·V형 쿠션고무를 **둘 다** 팝니다.
  그러나 **현장에서는 V형을 잘 안 쓰고 O형을 씁니다** (2026-09-29 주인).
- 자료와 현장이 다르면 **주인께 여쭙니다.** 혼자 정하지 않습니다.

## 5. 그림 조건은 **좁은 이름을 넓은 이름보다 위에**

`_부품모양()` 은 위에서부터 보고 맞으면 거기서 끝냅니다.
그래서 넓은 이름이 위에 있으면 **좁은 이름을 통째로 가로챕니다.**

```
✗ if '고무' in 이름:   ← 「찌멈춤고무」까지 먹어 검은 알갱이로 그림
✗ if '봉돌' in 이름:   ← 「좁쌀봉돌」까지 먹어 고리봉돌로 그림
```

**「좁쌀」·「찌멈춤」·「막대찌」처럼 긴 이름을 먼저 둡니다.**
이 둘은 **실제로 틀린 그림이 배포까지 나갔습니다.**

## 6. 새 부품을 넣으면 **그림도 함께** 넣습니다

모양이 없으면 `_부품모양()` 이 `''` 을 돌려주고 **빈 자리만 남습니다.**
막대찌가 그랬습니다 — 아무것도 안 그려질 뻔했습니다.

**`engine/check_rigs.py` 가 이것을 잡습니다.** 자료의 모든 부품이
그림을 갖는지 전수로 봅니다.

## 7. 근거를 반드시 남깁니다

`rigs.json` 의 `_근거` 에 **어디서 봤는지와 함께** 적습니다.
나중에 값이 의심스러울 때 되짚을 수 있어야 합니다.
「스스로 잡은 잘못」도 적습니다 — 같은 실수를 되풀이하지 않으려고.

## 8. 갯바위·방파제 낚시만 싣습니다

**선상낚시는 넣지 않습니다** (주인 규칙 10).
낚시점 목록에 「선상 외수질」·「심해」가 있어도 거릅니다.

## 8-1. **부품 크기는 실제 비율에 맞춥니다**

> **주인 지시 (2026-09-30)** — 「부품의 크기가 실제크기가 아니야
> 어떤건 크고 어떤건 너무 작고 이러네」
> 「각 부품별 크기에 맞게 비율을 조절해 가장 유사하게 그림을 그릴것」

부품마다 **실제 크기(mm)** 를 `engine/art.py` 의 `_실제크기mm` 표에
적고, 그 값으로 그림 크기를 정합니다. **눈대중으로 그리지 않습니다.**

| 부품 | 실제 크기 |
|---|---|
| 막대찌 | 150~250mm — **가장 큽니다** |
| 에기 | 75~105mm (2.5~3.5호) |
| EVA 찌 | 60mm 안팎 |
| 엉킴방지봉 · 구멍찌 | 30~40mm |
| 수중찌 | 25~35mm |
| 봉돌(고리) · 바늘 | 18~20mm |
| 맨도래 · 찌멈춤고무 | 8~12mm |
| 반달구슬 · O형 고무 | 4~7mm |
| 좁쌀봉돌 | 3~5mm — **가장 작습니다** |

**있는 그대로 쓰면 안 됩니다.** 좁쌀봉돌(4mm)은 막대찌(200mm)의
1/50 이라 점으로 보여 무엇인지 알 수 없습니다.
**제곱근으로 눌러** 1/7 쯤으로 만듭니다 — 큰 것과 작은 것이 갈리면서도
둘 다 알아볼 수 있습니다.

**새 부품을 넣으면 `_실제크기mm` 에도 한 줄 더합니다.**
표에 없으면 배수가 1.0 이 되어 **혼자 크거나 작아 보입니다.**

## 9. 다 만든 뒤에 **전수검사**합니다

```bash
python engine/check_rigs.py --strict
```

- 모든 채비에 이름·대상·장비·부품·왜·근거가 있는가
- 모든 부품이 **그림을 갖는가** (빈 자리가 없는가)
- 갈래마다 아이콘(`assets/icon/{갈래}.svg`)이 있는가
- 쪽이 실제로 만들어졌는가

그리고 **화면을 찍어 주인께 보여 드립니다** (규칙 6-2).
기계가 통과한 것과 사람 눈에 좋은 것은 다릅니다.

## 11. **막대찌는 줄에 꿰지 않습니다**

> **주인 지시 (2026-09-30)** — 「막대찌는 가로로 끝쪽에 살짝 걸치게
> 만들어야해 막대찌 홀더에 막대찌를 꼽는 형식이야」

구멍찌는 몸 가운데 구멍으로 원줄이 지납니다.
**막대찌는 구멍이 없습니다.** 홀더의 **스냅에 머리 한쪽만** 걸려
원줄 옆으로 눕습니다. 그래서 채비도에서도 **거의 가로로 걸쳐** 그립니다.

주인이 보내 주신 **실물 사진**에서 확인한 차례

| | 부품 | 생김새 |
|---|---|---|
| 1 | 면사매듭 | 분홍 실 |
| 2 | 찌멈춤고무 | 흰 작은 원통 |
| 3 | **막대찌홀더** | **검은 몸통 + 은색 스냅** — 여기에 막대찌를 겁니다 |
| 4 | 찌멈춤고무 | 형광 노랑 긴 원통 |
| 5 | 수중찌 | 갈색 방추꼴, 위아래에 연두 고무 |
| 6 | 쿠션고무 | 빨간 작은 것 여럿 |
| 7 | 구슬 | 갈색 둥근 것 |
