# 카페24가 cron 을 지원하는가 — 읽기 전용 조사

총감독 지시 2026-10-10 — 「A(서버 cron)로 가되, **카페24 cron
지원 여부를 먼저 읽기 전용으로 확인**하고 안 되면 B 로 전환」

**서버에 접속하지 않았습니다.** 공식 도움말과 상품 쪽을 읽기만
했습니다.

---

## 1. 찾은 것 — 공식 도움말

출처: 카페24 고객센터 「단독웹호스팅에서 CRON 기능을 사용하고
싶습니다」 (4년 전 갱신)
<https://cafe24.zendesk.com/hc/ko/articles/6471250778393>

적힌 그대로

> 사용중인 **단독웹호스팅** ID로 카페24 호스팅센터 로그인 후,
> **[나의서비스관리] > [크론서비스]** 페이지에서 직접 설정하여
> 사용 가능합니다.
> **직접 SSH 터미널에서 crontab cmd 로 설정하는 것이 아닌**
> 나의서비스 관리 페이지를 통해 관리되도록 하였으며 …

PHP 파일을 돌릴 때 지키라는 것

| 무엇 | 어떻게 |
|---|---|
| 권한 | `chmod 750 파일명` |
| 줄바꿈 | `dos2unix 파일명` 으로 유닉스 꼴로 |
| PHP 첫 줄 | `#!/usr/local/php73/bin/php` 같은 **실행 경로**를 맨 위에 |
| MySQL 쓸 때 | 홈에 빈 `.my.cnf` 를 만들어 둘 것 |
| 경로 | **반드시 절대경로** |

그리고 — 「등록한 크론 스크립트의 소스 체크나 구동 결과까지
가이드하지 않으며, **정상적으로 크론 실행을 시도하는 환경까지만**
확인해 드립니다」

---

## 2. 아직 **모르는** 것 — 가장 중요한 것

**바다가자가 쓰는 상품이 「단독웹호스팅」인지 모릅니다.**

공식 문서는 단독웹호스팅 기준입니다. 일반 웹호스팅에서도 되는지
는 검색으로 **확인하지 못했습니다.** 커뮤니티 글에 「가상호스팅은
직접 쓸 수 있고 단독은 따로 신청」이라는 말이 있었으나 3년 전
것이고 공식이 아니라 **믿지 않습니다.**

상품명이 저장소 어디에도 적혀 있지 않습니다. 배포 설정에는
FTP 주소와 비밀값만 있고(제가 보지 않습니다) 상품명은 없습니다.

---

## 3. 알아낸 것의 뜻 — 설계에 영향이 있습니다

### ㉠ **제가 cron 을 걸 수 없습니다**

SSH 로 `crontab` 을 쓰는 것이 아니라 **호스팅센터에 로그인해
웹 화면에서** 등록합니다. 로그인은 최종결정자만 할 수 있고,
저는 비밀값을 받지 않습니다.

→ A 로 가더라도 **마지막 한 걸음은 사람 손**입니다. 제가 할 수
  있는 것은 `api/snapshot.php` 를 만들고, **무엇을 어떤 주기로
  등록하면 되는지 한 줄로 적어 드리는 것**까지입니다.

### ㉡ PHP 파일 첫 줄에 실행 경로가 필요합니다

`#!/usr/local/php73/bin/php` 꼴입니다. **서버의 PHP 판을 모르면
못 적습니다.** 이것도 확인이 필요합니다.

### ㉢ 줄바꿈을 유닉스 꼴로 맞춰야 합니다

제가 쓰는 파일은 이미 LF 입니다(`.gitattributes` 가 `* text
eol=lf`). 이 점은 걸릴 것이 없습니다.

---

## 4. 그러면 B 가 나은가 — 다시 견줌

㉠ 때문에 A 의 「사람 손이 안 든다」는 장점이 **처음 한 번은**
깨집니다. 다만 **한 번 등록하면 그 뒤로는 사람 손이 없습니다.**
B 도 깃허브에 비밀값을 넣는 **처음 한 번**이 필요하니 같습니다.

| | A 서버 cron | B 깃허브 액션 |
|---|---|---|
| 처음 한 번 | 호스팅센터에서 **사람이 등록** | 깃허브에 **비밀값을 사람이 등록** |
| 그 뒤 | 손 안 감 | 손 안 감 |
| 비밀값이 사는 곳 | 서버 하나 | 서버 + **깃허브** 둘 |
| 원자료가 서버 밖으로 | **안 나감** | 안 나감(집계만 받아 옴) — 다만 열쇠말이 나감 |

**여전히 A 가 낫다고 봅니다.** 둘 다 처음 한 번 사람 손이
필요하다면, **비밀값이 한 곳에만 있는 쪽**이 안전합니다.

---

## 5. 확인해 주셔야 할 것 둘

제가 알아낼 수 없는 것입니다.

1. **바다가자의 카페24 상품이 무엇인가** (단독웹호스팅인가)
   → 호스팅센터 로그인 뒤 [나의서비스관리] 에 **「크론서비스」
     메뉴가 보이는지**만 봐 주시면 됩니다. 보이면 A 로 갑니다.
2. **서버의 PHP 판** (7.3 인지 8.x 인지)
   → `api/` 에 이미 php 파일이 돌고 있으니, 그것이 어떤 판에서
     도는지 알면 첫 줄 경로를 맞출 수 있습니다.

둘 다 **읽기만 하면 되는 확인**이고, 비밀값을 제게 주실 필요는
없습니다.
