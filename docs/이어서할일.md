## 5. ★ 반드시 알아야 할 함정

| 함정 | 어떻게 되나 |
|---|---|
| **차림표 맨 뒤 규칙** | 앞의 `@media` 를 **조용히 덮습니다.** 오늘 세 번 당했습니다. 덧붙일 때는 처음부터 미디어쿼리로 감쌉니다 |
| **쪽 틀 밖에 둔 칸** | 좌우 여백이 없어 **화면 밖으로 넘칩니다.** 오늘 세 번. `max-width:var(--wrap)` + `padding:0 var(--gutter)` |
| **클래스를 더하면** | `class="when"` 에 하나 더했더니 `check_actionable` 이 **못 찾았습니다.** 검사기가 글자 그대로 보는 것이 있습니다 |
| **셸 히어독에 한글** | `cat <<'EOF'` 가 깨집니다 — 긴 파일은 Write 도구로 |
| **지피티에 보낼 글의 백틱** | 템플릿 리터럴이 끊깁니다 — 배열 + join |
| **`--window-size=390`** | **거짓 그림**. `engine/shot_tide.py` 를 씁니다 |
| **크롬 `--screenshot` 상대경로** | 크롬 자기 자리에 씁니다. **절대 경로**로 |
| **없는 CSS 이름** | 오류 없이 **조용히** 버려집니다 |
| **CRLF 섞임** | `site.css`·`build.py` 는 CRLF. 덧붙일 때 `newline=''` 로 읽고 `\r\n` 으로 씁니다 |
| **`.htaccess` 에 BOM** | **무조건 500** |
| **`.tg-plot`·`.tm-pin` 클래스 이름** | 다른 코드가 이것으로 판단합니다. 바꾸면 안 됩니다 |
| **정규식에 낱말 경계 기호** | 도구를 거치며 먹혀 검사가 조용히 죽습니다 |
| **측정 표기** | 「몇 화면 내려야」(0부터)와 「몇 번째」(1부터)를 **둘 다** 냅니다 |
