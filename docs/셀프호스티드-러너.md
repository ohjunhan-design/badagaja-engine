2026-09-30 주인 지시 — 「깃허브 무료 이용방법」

## 왜

| | 깃허브 우분투 | 내 컴퓨터 |
|---|---|---|
| 비공개 저장소 요금 | **듭니다** (월 2,000분 무료) | **0원** |
| 판정 한 번 | 12~13분 | **3~5분 목표** |
| 파이썬·크롬 | **매번 새로** 깝니다 | 이미 있습니다 |
| 사진 378장 | 매번 새로 받음 | 이미 있습니다 |

## 어디에 있나

    C:\actions-runner\

    run.cmd      러너 띄우기
    config.cmd   등록·해제
    .env         **환경 변수** — 깃 배시 경로를 여기 적었습니다

## 어느 컴퓨터에서 돌지 고르기

일꾼 파일을 고치지 않습니다. **저장소 변수 하나**로 정합니다.

    Settings → Secrets and variables → Actions → Variables
    RUNNER_LABEL = badagaja      ← 내 컴퓨터
    (변수를 지우면 예전처럼 깃허브 우분투)

## 러너 붙이며 걸렸던 것들 — 네 가지

### ① setup-python 이 레지스트리 권한으로 죽음

    Remove-Item : Requested registry access is not allowed.

관리자가 아닌 러너에는 레지스트리 쓰기 권한이 없습니다.
**우분투일 때만** 깔고, 윈도우에서는 있는 파이썬이 3.12 인지 봅니다.

### ② 같은 오류 — 범인은 크롬이 아니라 파이썬이었습니다

오류 글만 보고 크롬을 먼저 고쳤다가 헛돌았습니다.
**「어느 단계에서 났는가」를 먼저 봐야 합니다.**

### ③ 파워셸이 셸 문법을 못 읽음

    ParserError: if [ -z "$X" ]; then
    'if' 뒤에 '('가 없습니다

윈도우 러너는 `run:` 을 기본으로 파워셸로 돕니다.
일꾼에 `defaults: run: shell: bash` 를 못 박아
**우분투와 윈도우가 같은 글을 쓰게** 했습니다.

### ④ bash 가 경로에 없음

    Error: bash: command not found

깃 배시는 깔려 있는데 러너가 못 찾았습니다.
`C:\actions-runner\.env` 에 이렇게 적었습니다.

    PATH=C:\Program Files\Git\bin;C:\Program Files\Git\usr\bin;%PATH%

**러너를 다시 띄워야** 이 파일을 읽습니다.

## 안전 — 공개 저장소에서는 위험합니다

깃허브가 이렇게 경고합니다.

> 공개 저장소에서 셀프 호스티드 러너를 쓰는 것은 권하지 않습니다.
> 포크한 사람이 풀 리퀘스트로 **내 컴퓨터에서 코드를 돌릴 수** 있습니다.

그래서 먼저 이렇게 잠갔습니다.

    Settings → Actions → General → Fork pull request workflows
    → **Require approval for all external contributors**

**저장소를 비공개로 바꾸면** 이 위험이 사라집니다.
비공개로 바꿔도 러너를 쓰므로 **요금은 0원 그대로**입니다.

## 러너가 멈췄을 때

    // 지금 도는지
    tasklist | findstr Runner

    // 다시 띄우기
    C:\actions-runner\run.cmd

    // 아예 끄고 깃허브로 돌아가기
    저장소 변수 RUNNER_LABEL 을 지웁니다

## 아직 안 한 것

**윈도우 서비스로 등록** — 관리자 권한이 필요합니다.
서비스로 등록하면 컴퓨터를 켤 때마다 저절로 돕니다.

    관리자 파워셸에서
    cd C:\actions-runner
    .\svc.cmd install
    .\svc.cmd start
