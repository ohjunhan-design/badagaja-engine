# 기준선 운영 규칙 — 정말 듣는지 시험한 기록

총감독 확정 2026-10-10. 「기준선이 **오류를 영구 면제하는 목록**이
되면 안 됩니다」 하여 규칙 여덟 가지를 받았고, 그 가운데 코드로
박을 것 넷을 넣었습니다. **넣었다고 말하지 않고 망가뜨려 봤습니다.**

도구 `engine/check_classes.py` · 기준선 `tests/golden/없는클래스.json`

## 시험한 것 다섯

| 무엇을 망가뜨렸나 | 바란 것 | 나온 것 |
|---|---|---|
| 기준선 한 줄의 `까닭` 을 빈 글자로 | 알림(막지는 않음) | `! 까닭이 안 적힌 것 1가지 — tbl` · 끝난값 0 |
| 쪽에 없는 이름 `옛날에쓰던것` 을 기준선에 | 쓰임없음 알림 | `! 기준선에 있는데 쪽에서 사라진 이름 1가지` · 끝난값 0 |
| 기준선에서 `tbl` 을 빼고 `--받아들이기` | **막음** | `✗ 기준선에 새 이름을 혼자 더하지 않습니다 — 1가지` · **끝난값 1** |
| `p-` 를 기준선에 억지로 넣고 쪽도 되돌림 | **막음** | `✗ 새로 생긴 것 1가지 — .p- 1쪽` · **끝난값 1** |
| 차림표에서 `.rig-kit-note` 규칙 이름을 바꿈 | **막음** | `✗ 새로 생긴 것 1가지` · **끝난값 1** |

모두 되돌린 뒤 **끝난값 0** 으로 돌아옵니다.

## 끝난값을 파이프 없이 봤습니다

처음에 `| tail` 을 거쳐 보고 「잡았는데 끝난값 0」이라 여겼습니다.
`tail` 의 끝난값이었습니다. 파이프 없이 파일로 받아 다시 쟀습니다.

## 기준선 19가지의 까닭

짐작이 아니라 **쪽을 크롬으로 그려** computed style 을 재고,
부모가 자리를 잡는지·다른 규칙이 꾸미는지 보고 적었습니다.
(`scratchpad/기준선조사.py`)

세 갈래였습니다.

* **부모가 자리를 잡음** — `fn-col`(꼬리, 부모 grid) ·
  `area-chip` · `fish-rig-say` · `gc-body` · `hm-left`
* **다른 규칙이 꾸밈** — `filters`(`.filters--fish`) ·
  `firsttime`(`.firsttime--btn`) · `tbl`(`.st-table table`) ·
  `p-guide` · `p-rule` · `fest-pick` · `g-book` · `rl-now` ·
  `tp-guide` · `tv-shots`
* **표가 자리를 잡음** — `rl-ok` · `rl-bad` · `rl-warn` · `rl-row`

## 재다가 찾아 고친 둘

* `.warn-small` **35쪽** — 「해경이 지정한 출입통제 장소에
  들어가면 과태료 대상입니다」 같은 경고문. 바로 위 목록과
  들여쓰기가 어긋나 튀어나온 것처럼 보였습니다.
* `.ft-more` **57쪽** — 「왕초보 바다낚시 기초 →」 링크 넷이
  공백 하나로 붙어 나왔습니다.

기준선 21 → 19가지.

## 제가 한 번 잘못 짚은 것

금어기 표의 `rl-ok`·`rl-bad`·`rl-warn` 을 보고 「지금 금어기와
해당 없음이 빛깔로 구별되지 않는다, 법 문제라 위험하다」고
판단했습니다. **화면을 보니 틀렸습니다.** 구별은 속의 이름표가
빛깔로 이미 합니다 — 지금 금어기 빨강 · 크기 제한 노랑 ·
해당 없음 녹색. 줄 클래스에 규칙이 없어도 됩니다.
