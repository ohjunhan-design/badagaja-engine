## 0. 먼저 말씀드릴 것 — 「필요없는 검사」가 거의 없습니다

검사기 74가지의 머리글을 **전수로 읽었습니다.** 거의 모두가
**실제로 터진 사고 뒤에** 생겼습니다.

| 어디서 왔나 | 보기 |
|---|---|
| 주인이 직접 시키심 | 엄지가닿나 · 눈으로볼때 · 글이읽히는가 · 걸러내기 · 눌러보기 (2026-10-08 밤) · 약속지킴 (「왜 자꾸 빠트려 똑바로해」) |
| 바깥 검수가 지적 | 사진 · 아이콘 · canonical · hreflang · 콘솔 · 멱등성 … |
| 제가 실제로 당함 | `.rig-zoom` 이 두 뜻이라 확대 그림이 채비 16쪽을 덮음 · 일꾼에 Pillow 가 없어 38쪽 사진 크기를 (0,0) 으로 읽음 · `origin` 이 멈춘 저장소를 가리킴 · 선상낚시가 채비 쪽 둘에 샘 |

그래서 **지울 것을 찾는 분류가 아닙니다.** 「언제 도느냐」를
나누는 분류입니다. 지우면 그 사고가 **그대로 돌아옵니다.**

## 3. 줄어드는 시간 — **정직하게 둘로 나눠 적습니다**

### ㉠ 확실한 것 — 상한 기준

| | 가짓수 | 상한 합 |
|---|---|---|
| 덧검사 전체 | 44 | 602분 |
| QUALITY 로 뺌 | 16 | **423분 (70%)** |
| FAST 에 남음 | 28 | 179분 (30%) |

### ㉡ **아직 모르는 것 — 실제로 몇 분 줄어드는가**

**상한은 실측이 아닙니다.** 판정 #161 은 상한 합이 602분인데
실제로는 **42분 16초**에 끝났습니다. 병렬로 돌고(무거운 것 2,
가벼운 것 6), 대부분 상한보다 훨씬 빨리 끝나기 때문입니다.

그러니 **「70% 준다」고 말하면 거짓입니다.** 실제로는 가장
오래 걸리는 몇 개가 전체 시간을 정합니다.

최근 판정 실측 — #156 14분30초 · #157 23분47초 · #159 33분26초 ·
#160 47분13초 · #161 **42분16초**

**실측을 얻는 법**: `gate.py:449` 가 항목마다
`%5.1f초 (여태 %4.0f초)` 를 이미 찍습니다. 다음 판정 로그에서
그 줄만 긁으면 **항목별 실측**이 나옵니다. 이번에 받으려 했으나
깃허브가 로그를 따로 가져와 브라우저로는 못 받았습니다
(세 번 시도). 아티팩트 「판정결과」(66.7KB)에 있을 수 있습니다.

→ **숫자를 지어내지 않겠습니다.** 다음 판정 때 실측을 받아
  「FAST 만 돌리면 ○분」을 정확히 올리겠습니다.

## 4. 어떻게 나누나 — 파일은 안 건드립니다

`gate.py` 의 목록 항목에 묶음 한 칸을 더합니다.

```python
('덮는것', 'check_cover.py', ['--all'], 2700,
 '본문 위에 올라앉아 손님 눈을 가리는 것이 없는가',
 'QUALITY'),          # ← 이 한 칸만 더합니다
```

`gate.py --fast` 면 QUALITY 를 건너뛰고, 아무것도 안 붙이면
지금처럼 **전부** 돕니다. 즉 **기본값은 지금 그대로**이고,
평소 판정 워크플로만 `--fast` 를 붙입니다.

**검사기 파일은 한 글자도 안 고칩니다.** 지우지도, 끄지도
않습니다. 건너뛴 것은 결과표에 **「이번엔 안 봄(QUALITY)」**
으로 또렷이 적어, 통과로 오해하지 않게 합니다.
(이것이 빠지면 **거짓 통과**가 됩니다 — 가장 조심할 곳입니다.)

## 5. 되돌리는 법 — 한 줄

```
.github/workflows/gate.yml 에서 `--fast` 를 지웁니다.
```

그러면 74가지가 다시 전부 돕니다. 코드 되돌림이 필요 없습니다.

## 6. 위험 둘 — 미리 적어 둡니다

1. **QUALITY 를 아무도 안 돌리면 그냥 끈 것과 같습니다.**
   주 1회 깃허브 일정(cron)으로 저절로 돌게 하고, 결과를
   이슈로 올려야 합니다. 그것까지 해야 「보관」입니다.
2. **건너뛴 것을 통과로 세면 거짓 통과입니다.**
   결과표·최종 판정 모두 「안 봄」을 **통과와 따로** 세야
   합니다. `tests/test_not_tested.py` 에 시험을 더합니다.

## 7. 승인받고 싶은 것

1. 2절의 **QUALITY 16 + 본검사 2·4** 묶음을 이대로 둘지
2. QUALITY 를 **주 1회 자동**으로 돌릴지 (안 돌리면 끈 것과 같음)
3. 실측을 얻기 위해 **판정 로그/아티팩트를 받아도 될지**
   (읽기만 합니다)

승인 전에는 `gate.py` 와 `gate.yml` 을 고치지 않습니다.
