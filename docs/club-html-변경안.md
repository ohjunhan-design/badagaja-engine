# `badagaja.com/club.html` 변경안 (반영 안 함)

2026-10-09 · 감독팀 지시 — BADA-ORG-001(도메인 분리)과 어긋나는
링크 1건. 긴급 장애는 아닙니다.

**변경안만 만들었습니다. 서버를 건드리지 않았습니다.**

---

## 1. 무엇이 문제인가 — 정확히 네 줄입니다

`https://badagaja.com/club.html` (21,073 바이트) 의 **149~152줄**.

```html
149  <h2>같이 다닐 분을 찾고 있습니다</h2>
150  <p>창립회원을 모집하고 있습니다. 회비도, 등급도 없습니다.
     물때가 맞는 날 같이 나가고, 같이 나오는 것이 전부입니다.</p>
151  <a href="https://badagaja.cloud/" target="_blank" rel="noopener">
     동호회 신청하러 가기 →</a>
152  <small>신청은 동호회 쪽(badagaja.cloud)에서 받습니다</small>
```

문제가 **둘**입니다.

| | 무엇 |
|---|---|
| ㄱ | `badagaja.cloud` 로 보냅니다 — **BADA-ORG-001 어김** |
| ㄴ | 「**창립회원을 모집하고 있습니다**」 — 마감한 모집입니다 |

그리고 **cloud 를 비우면 이 링크가 빈 쪽으로 갑니다.**

### 이 쪽이 어떤 쪽인가

- 새 판 450쪽이 **만들지 않는** 쪽입니다 (옛 판 잔재)
- 새 판에서 **들어가는 길이 0개**입니다
- 그래도 주소를 치거나 검색 결과로 들어오면 열립니다 (200)

---

## 2. 고치는 길 셋

| | 무엇을 | 좋은 점 | 걸리는 점 |
|---|---|---|---|
| **ㄱ** | **`/club.html` 통째로 `club/support.html` 로 301** | 옛 링크·검색 결과가 새 쪽으로 이어집니다. **한 줄이면 끝납니다** | `.htaccess` 를 고쳐야 합니다 (주인 규칙 27) |
| ㄴ | 네 줄만 고쳐 다시 올림 | `.htaccess` 를 안 건드립니다 | **옛 판 쪽을 계속 살려 둡니다.** 새 판이 안 만드는 쪽을 손보는 셈이라, 다음에 또 어긋납니다 |
| ㄷ | 지움 | 깔끔합니다 | 검색 결과에서 404. 들어온 분이 막다른 곳에 닿습니다 |

### 제 의견 — **ㄱ(301)**

ㄴ 은 **옛 판 쪽을 계속 끌고 가는 것**입니다. 새 판이 안
만드는 쪽을 손으로 고치면, 다음에 또 같은 일이 생깁니다
(기억: 쪽을 고쳤으면 생성기도 함께 — 여기는 생성기가 없습니다).

ㄱ 은 **그 쪽을 아예 새 쪽에 넘깁니다.** 손님이 「동호회」를
찾아 들어오면 `club/support.html`(동호회 지원)에 닿습니다 —
찾던 것과 가장 가깝습니다.

### 넣을 줄 (한 줄입니다)

```apache
Redirect 301 /club.html /club/support.html
```

`.htaccess` 는 **주인 규칙 27** 이 걸립니다 —
한 번에 하나씩 · 올린 뒤 응답 코드 확인 · 500 이면 먼저 되돌림 ·
**BOM 없이 저장**(`encoding='utf-8'`).

> 서버 잔재 11개 가운데 `point/busan.html` 등 다섯도 같은
> 처지입니다. 다만 **한 번에 하나씩**이라는 규칙에 따라
> `/club.html` 만 먼저 하는 것이 맞습니다.

---

## 3. ★ 순서 — cloud 를 먼저 비웁니다

```
① cloud 정리 (포맷 · 새 첫 쪽 올리기)
② /club.html 처리 (301)
```

**거꾸로 하면 안 됩니다.** ②를 먼저 하면 cloud 가 아직 모집
쪽인 채로 링크만 바뀌어, 두 사이트가 다른 말을 하는 상태가
길어집니다.

①을 먼저 하면 cloud 는 「오픈 준비 중」이 되고, `/club.html`
은 그 사이 **잠깐 빈 쪽을 가리킵니다.** 그 쪽으로 들어오는
길이 0개라 실제로 보는 사람은 거의 없습니다.

---

## 4. 반영은 승인된 단독 배포로만

감독팀·지피티 모두 「비배포 범위」로 보류했습니다.
**주인이 「이것만 올려라」 하실 때** 하겠습니다.

올릴 때 차례 —

```
□ .htaccess 를 내려받아 백업
□ 한 줄 더함:  Redirect 301 /club.html /club/support.html
□ BOM 없이 저장했는지 확인  (head -c 6 .htaccess | xxd 에 efbbbf 가 없어야)
□ 올림
□ curl -s -o /dev/null -w '%{http_code}' https://badagaja.com/
     → 200 이어야 합니다. 500 이면 **곧바로 되돌립니다**
□ curl -sI https://badagaja.com/club.html
     → 301 이고 Location 이 /club/support.html 인지
□ https://badagaja.com/club/support.html 가 200 인지
```
