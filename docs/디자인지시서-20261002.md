# 디자인 작업 지시서 (2026-10-02 · 바깥 검수)

주인이 지피티에 직접 맡긴 지시서입니다. **디자인 판단은 지피티**가 합니다.

## 완료 기준이 바뀌었습니다

> **「이번 작업은 검사 통과가 완료 기준이 아닙니다. 실제 사람이 보기에
>   아름답고, 읽기 편하며, 사용하고 싶어지는 화면이 완성 기준입니다」**

주인 규칙 6-2 와 같은 말입니다 — 기계가 통과한 것과 사람이 편히 보는
것은 다릅니다.

## 일하는 차례 (바뀐 절차)

1. **사전 조사** — 실제 HTML·CSS·자료·사진 자산을 먼저 확인.
   있는 것을 쓸 수 있는지 보고, 모자란 그림은 **지피티에 제작 요청**
2. **실제 자료로 시안** — 빈 카드·가짜 숫자로 디자인하지 않습니다.
   **가장 복잡해지는 경우**를 기준으로 만듭니다
   (간조·만조가 **네 번** 나는 날 같은 것)
3. **화면 제출** — PC **1440px**, 모바일 **360·390·412px**
4. **지피티가 시각 완성도 검수** — 가독성뿐 아니라 사진·색감·여백·
   전체적인 아름다움까지
5. **승인된 것만 전국 확대** — 제주 시안 승인 전에는 다른 권역에
   손대지 않습니다
6. 기존 검사·배포 검증으로 자료·검색·휴대폰 기능이 안 깨졌는지 확인

## 사진 규칙

- 실제 사진으로 쓸 수 있는 자료만 씁니다
- **AI 그림을 실제 현장·축제 개최 사진처럼 소개하지 않습니다**
- 기존 이용허락 사진은 권리 조건대로, AI 그림은 **출처를 따로** 관리

## 1순위 — 물때 달력

지금 탈: 14일치가 너무 촘촘해 간조·만조 시각·물높이를 읽기 어렵습니다.

- PC 기본을 **5열 × 2행, 10일**로
- 카드 안 차례: 날짜·요일 → 물때 번호 → 물살 → **만조·간조 시각** →
  물높이·증감량
- **시각을 가장 크게**, 물높이·증감량은 보조
- 오늘은 **브랜드 녹색**으로 강조. 다른 날은 색을 과하게 쓰지 않음
- **14일 자료를 지우지 않습니다.** 10일 보이고 나머지는
  「이후 날짜 더 보기」
- 휴대폰은 **1열** 방식과 **날짜를 골라 상세 보기** 방식을 **견줘 봄**
- **간조·만조가 네 번 나는 날**로 시안 제작

## 2순위 — 물때 그래프

지금 탈: 그래프와 배경 명암 차가 작고, 관측소·출처 글씨가 너무 크며,
주변 카드와 안 어울리고, 현재 시각 표시가 직관적이지 않습니다.

- **독립 카드형**으로. 부드러운 크림색/밝은 배경
- 연한 청록 물높이 영역 · 선명한 **브랜드 녹색 곡선**
- **간조 녹색 · 만조 주황**
- 시각은 **그래프 위 별도 영역**, 그래프 안에는 곡선·작은 점·
  현재 세로선만 (※ 이미 해 둔 것)
- 시간축 **0 / 12 / 24시** (※ 이미 해 둔 것)
- 현재 시각은 **얇은 세로 점선 + 작은 「지금」**
- **관측소·출처는 그래프 아래 작은 보조 글씨로**
- 높이·여백을 주변과 어울리게

## 3순위 — 축제 달력 (주인 추가 지시)

> 주인 — 「달마다 다른얼굴 디자인도 수정해 좀 예쁘게 보이는게
>   중요하잖아 축제인데」

지피티 진단: 「축제 달력이라기보다 **월별 행사 목록표**에 가깝습니다.
1·2·6월처럼 축제가 없는 달은 **커다란 빈 상자**가 공간만 차지합니다」

- **사진 중심의 여행 콘텐츠**로 재설계
- 위쪽에 **계절별 대표 사진**(봄 3~5 · 여름 6~8 · 가을 9~11 ·
  겨울 12~2)과 탐색 기능. **실제 개최 월과 맞게**
- 축제 카드에 — 대표 사진 · 축제명 · 지역 · 통상 개최 월(또는 확인된
  일정) · 상세 쪽으로 가는 길
- **축제 없는 달을 큰 빈 상자로 만들지 않습니다.** 작은 월 단추나
  간결한 안내로
- PC 는 **사진 3열 카드** 먼저 검토, 휴대폰은 1열·2열을 **견줘** 사진과
  글자가 넉넉한 쪽
- **기존 월별 탐색 기능과 모든 상세 링크는 유지**
- 사진이 없으면 지피티에 제작 요청 가능. 단 **실제 개최 현장 사진처럼
  쓰지 않습니다**
- **제주부터 시범 제작 → 승인 후 전국**
