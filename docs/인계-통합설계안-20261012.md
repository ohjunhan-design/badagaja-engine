## 2. 충돌 — 그대로 올리면 깨지는 것 넷

### ㉠ 주소가 **엔진에 없습니다**

인계 ZIP 은 `beginner.html` · `intermediate.html` · `advanced.html`
세 쪽을 전제합니다. 엔진에는 그런 길이 없습니다.

```

                → guide/fishing-levels.html  (한 쪽)
  만드는 자리   engine/build.py:6866·6965·7099  갈래 '낚시트랙'
```

세 쪽으로 가르려면 **라우트·만들목록·쪽갈래**를 모두 늘려야 합니다.

`preview.html` 은 독립 쪽이라 사이트 머리띠·꼬리 메뉴가 없습니다.
그대로 올리면 **사이트에서 뚝 떨어진 쪽**이 됩니다.
(지금 쪽도 머리띠가 다른 450쪽과 어긋나 있는데 — 검수 대기 ㉠ —
인계본은 아예 없으니 더 심합니다)

### ㉢ 차림표가 또 늘어납니다

인계본은 `<style>` 을 쪽 안에 씁니다. 지금 쪽은 옛 `css/style.css`,

## 4. 제 생각

**㉮ 를 먼저 하고, 주인 검수 뒤에 ㉯ 또는 ㉰ 를 정합니다.**

까닭 —

1. **㉮ 는 이미지 없이 지금 할 수 있습니다.** 그리고 넷 중 가장
   값진 것(안전 정보)을 가져옵니다. 「너울」과 「동행」이 빠진 채로
   고급 갯바위를 안내하는 것은 흠입니다.
2. ㉯ 는 **버리는 것이 아까울 수 있습니다.** 지금 SVG 도해도
   `시각기준`(사선 조감도)을 지키고 곶부리·수중여·와류를 그립니다.
   WEBP 가 더 나은지는 **나란히 놓고 봐야** 압니다 — 이미지가 와야
   견줄 수 있습니다.
3. ㉰ 는 **주인이 정하실 일**입니다. 검수 기록에 이미 여쭤 두었습니다.

### 받으면 가장 먼저 할 일

이미지 6장이 들어오면 **버리기 전에 나란히 찍어** 주인께 보여
드리겠습니다 — 지금 SVG 도해와 WEBP 를 같은 화면에. 그래야
「어느 쪽이 나은지」를 눈으로 고르실 수 있습니다.
