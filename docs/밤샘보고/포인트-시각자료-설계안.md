## 3. (2) `visual_type` 을 어디에 어떻게 넣을까

### 어디에 — `data/raw/points/*.json` (포인트 자료)

지금 한 포인트의 열쇠는 이렇습니다.

    id · 갈래 · 권역 · 대상 · 등급 · 메모 · 방법 ·
    배로가나 · 이름 · 좌표 · 지형 · 철 · 출입

여기 **`visual`** 하나를 더합니다. 사진 자료(`photos.json`)에
넣지 않는 까닭은, 시각자료가 **사진이 아닐 수 있기** 때문입니다.

### 어떻게 — 세 층으로 나눕니다

```
1층  규칙이 정합니다      지형 → visual_type  (3,603곳 모두 자동)
2층  자료가 덮어씁니다    visual.type 을 적으면 그것이 이깁니다
3층  파일이 있으면 씁니다  visual.file 이 있으면 그 그림을 씁니다
```

**1층(규칙)** 예시 — 지형을 보고 가립니다.

| 지형 | visual_type |
|---|---|
| 갯바위 · 갯바위·해안 | `cross_section` (단면 도해) |
| 방파제 · 선착장 · 방파제·항포구 | `cross_section` |
| 갯벌 · 조간대 | `cross_section` (물때와 함께) |
| 해변 · 해변·연안 | `map` (지도형) |
| ⚠️ 현장 판단 필요 | `map` + 주의 띠 |

**2층·3층**은 손으로 적는 자리입니다. 시범 두 건은 여기에
적어서 넣으면 됩니다.

```json
{
  "id": "taean-001",
  "지형": "갯벌",
  "visual": {
    "type": "cross_section",
    "file": "img/visual/cs-gaetbeol-01.svg",
    "설명": "간조 2시간 전 들어가 1시간 뒤 나옵니다"
  }
}
```

### 공통 컴포넌트는 어디에

`engine/visual.py` 를 새로 만듭니다. 지금 `art.py` 가 채비 그림을
그리듯, 시각자료의 **틀·여백·색·글자 크기**를 한 곳에서 정합니다.

- 지피티 명세(1600×900 · 안전 여백 72~96px · 대비 큰 글씨 3:1 ·
  본문 4.5:1 · 위험 빨강/주황 · 안전 청록/녹색 · 주의 머스터드)를
  **토큰으로** 박아 둡니다
- 쪽에서는 `visual.그리기(포인트)` 한 줄만 부릅니다
- **엔진에 이미 있는 것을 씁니다** — 크롬은 `machine.크롬앞머리()`,
  못 쟀을 때는 `mustmeasure`. (어젯밤 제가 새 도구에서 크롬을
  따로 불렀다가 판정이 막혔습니다)

### 검사기도 함께

`engine/check_visual_type.py` 를 만듭니다.

- 3,603곳 모두 `visual_type` 이 정해지는가 (안 정해지면 **못잼**)
- `visual.file` 이 적힌 곳은 **그 파일이 정말 있는가**
  (어젯밤 명소 사진 일곱 장이 자료에만 있고 파일이 없었습니다)
- 도해가 쪽에서 **1100px 를 넘게 그려지지 않는가**
- 390px 에서 **글자가 읽히는가**

## 4. 시범 두 건 — 어떻게 받을지

지피티가 제작 기준서·템플릿 명세서를 준다고 했습니다. 받으면
**제가 구현·배치하고 전수로 확인**합니다. 제가 그림의 내용을
지어내지 않습니다 (주인 지시 그대로).

| 시범 | 어느 포인트로 할지 제 제안 |
|---|---|
| 해루질 단면 도해 | **태안 만대어촌체험마을**(갯벌·좌표 있음·포인트 쪽 첫 칸) |
| 포인트 지도형 안내도 | **태안 해루질 39곳**(한 쪽에 39곳이라 지도가 값을 합니다) |

둘 다 태안으로 잡은 까닭은, **한 쪽에서 두 유형을 나란히** 보며
견줄 수 있어서입니다.

1. 사진을 **세 갈래로 나누는 것**(대표는 그대로 · 명소는 보조 ·
   포인트는 새 도해)에 동의하십니까
2. `visual` 을 **포인트 자료**에 넣는 것이 맞습니까
3. 시범을 **태안**으로 해도 될까요
4. 3,603곳에 도해를 **다 만들 수는 없습니다.** 지형별로 **대표
   도해 여덟 장**을 만들어 같은 지형끼리 쓰는 쪽이 현실적입니다.
