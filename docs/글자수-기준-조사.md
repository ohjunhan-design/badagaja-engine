# 글자 수 기준이 어디서 정해지나 — 전수 조사

2026-10-09 · 지피티 요청(「60자 규칙이 실제로 어디서 생성·검사되고
있는지 위치만 조사해 주세요」)에 따른 조사입니다.
**아무것도 바꾸지 않았습니다.** 어디에 무엇이 있는지만 적습니다.

---

## 결론 먼저

**이 저장소에는 「페이지 설명문 60자」 규칙이 없습니다.**

지피티가 말씀하신 「공통규칙에 한 줄 소개 40자·설명문 60자가
박혀 있다」는 `00_공통규칙` 문서의 내용으로 보입니다.
그 문서는 **이 저장소 밖**에 있습니다 — 저장소를 뒤져도
40자·60자 설명문 규칙은 나오지 않습니다.

저장소에서 실제로 쓰는 값은 이렇습니다.

| 무엇 | 값 | 어디 | 막나 |
|---|---|---|---|
| 쪽 **설명문** 최대 | **80자** | `engine/check_seo.py:46` (「네이버 가이드」라 적힘) | 알림만 |
| 쪽 **제목** 최대 | **60자** | `engine/check_seo.py:45` (「검색 결과에서 잘리지 않는 선」) | 알림만 |
| 카드 한 줄 글 | 44자 | `engine/build.py:6335` `카드글(글, 최대=44)` | — |

즉 **60자는 설명문이 아니라 제목 기준**입니다.
설명문 기준은 처음부터 80자였습니다.

---

## 1. 검사기 — 어디서 재나

```
engine/check_seo.py:45   제목최대 = 60          # 검색 결과에서 잘리지 않는 선
engine/check_seo.py:46   설명최대 = 80          # 네이버 가이드
engine/check_seo.py:242  if len(제목) > 제목최대:   → 적기(…, 막는가=False)
engine/check_seo.py:257  if len(설명) > 설명최대:   → 적기(…, 막는가=False)
```

**둘 다 막지 않습니다.** 넘어도 배포가 멈추지 않고 알림만 뜹니다.
지피티가 걱정하신 「60자 초과를 FAIL 처리」는 **일어나지 않습니다.**

그 밖에 40·60 이 나오는 곳은 글자 수와 무관합니다.

```
check_render.py:64        좁은누름 = 40        # px — 손가락 크기
check_hero_quality.py:44  작은파일 = 60 * 1024  # 사진 용량
```

## 2. 생성기 — 어디서 맞추나

```
engine/build.py:1650  포인트제목(…, 한도=60)   ← 2026-10-09 새로 만듦
engine/build.py:1679  포인트설명(…, 한도=80)   ← 2026-09-28 부터 있던 것
engine/build.py:5730  설명최대 = 80            ← 채비 쪽
engine/build.py:6335  카드글(글, 최대=44)       ← 화면 카드용
```

둘 다 **글을 자르지 않습니다.** 늘어놓을 포인트 이름 수를
셋 → 둘 → 하나로 줄여 한도 안에 넣습니다. 이름이 하나도
안 들어가면 그 구절을 통째로 뺍니다.

## 3. 자료 — 강제하는 곳 없음

`data/raw/*.json` 어디에도 글자 수 제한이 없습니다.
`CLAUDE.md`(주인 절대규칙)에도 없습니다.

## 오늘 제가 고친 것과의 관계

제목이 60자를 넘는 쪽이 **53개**(가장 긴 것 90자)였습니다.
`포인트제목()` 을 만들어 0 으로 만들었습니다.

- 고친 것은 **제목**입니다. 설명문이 아닙니다.
- **검사기를 건드리지 않았습니다.** 생성기가 기존 기준을
  지키게 했을 뿐입니다.
- 방식도 「자르기」가 아니라 **예시 수 줄이기**라, 지피티
  개정안의 「60자를 넘었다는 이유만으로 자르지 않습니다」와
  어긋나지 않습니다.

설명문은 80자 기준으로 재니 넘는 쪽이 **하나**였고
(`rig/landing.html` 81자) 같은 방식으로 고쳤습니다.

> 다른 세션이 「설명문 60자 초과 126쪽」이라고 알려 주었는데,
> **그 60자 기준이 이 저장소에 없습니다.** 실제 기준(80자)으로
> 다시 세니 1쪽이었습니다.

## 개정안이 들어오면 손댈 곳

주인이 승인하시면 바꿀 자리는 **두 곳뿐**입니다.

| 할 일 | 어디 |
|---|---|
| 설명문 한도 80 → 90 (또는 120) | `check_seo.py:46` · `build.py:5730` · `build.py:1679` |
| 카드용·검색용 분리 | 지금은 `카드글(44)` 과 `설명` 이 이미 갈려 있습니다 |

**카드용과 검색용은 이미 나뉘어 있습니다.** `카드글(최대=44)` 은
화면 카드에만, `설명` 은 `<meta name="description">` 에만 씁니다.
지피티가 걱정하신 「둘을 같은 규칙으로 묶어 SEO 문장이 지나치게
짧아지는 문제」는 이 저장소에서는 일어나지 않습니다.
