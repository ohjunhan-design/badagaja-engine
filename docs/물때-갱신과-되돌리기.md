# 미리 받은 물때 — 갈아 주는 법과 되돌리는 법

2026-10-14 주인 지시 「60일로 진행하고 이상이 발생할 경우에 대비해
장치를 만들어」에 따라 적습니다.

---

## 0. 한눈에

손님이 보는 물때는 **미리 받아 둔 파일**에서 나옵니다.

```
engine/fetch_tide.py  →  data/tide/{권역}.json   (받아 둠)
engine/build.py       →  site/assets/tide/*.json (사이트로 옮김)
FileZilla             →  운영 /assets/tide/      (손으로 올림)
손님                  →  그 파일을 바로 읽음 (8~16ms)
```

**정부 API 를 거치지 않습니다.** 그래서 정부가 멈춰도 화면이 멀쩡합니다.

---

## 1. 갈아 주는 차례

```bash
# ① 받습니다 (60일치 · 15~30분)
python -m engine.fetch_tide --날수 60

# ② 올려도 되는지 봅니다 ★ 이것을 통과해야 올립니다
python -m engine.check_tide_files

# ③ 사이트로 옮깁니다
python -m engine.build

# ④ (감독실) 운영에 올리기 전에 지금 것을 받아 둡니다 — 3번 항목
# ⑤ (감독실) site/assets/tide/ 57개를 운영 /assets/tide/ 로

# ⑥ 올린 뒤 봅니다
python -m engine.check_tide_live
```

★ ② 가 「**올리지 마십시오**」를 내면 **올리지 않습니다.**
  까닭이 함께 나옵니다. 대개 다시 받으면 풀립니다(빈 날은
  받을 때마다 다른 날이 비고, 합치기가 모읍니다).

---

## 2. 언제 갈아 주나

`check_tide_live` 가 알려 줍니다.

| 남은 날 | 뜻 |
|---|---|
| 14일 이상 | 넉넉합니다 |
| **14일 미만** | 갈아 줄 때입니다 |
| **7일 미만** | **폴백 임박** — 화면이 정부 API 로 되돌아갑니다 |

60일치를 받으면 **한 달에 한 번**이면 넉넉합니다.

★ 폴백되어도 **손님 화면은 멀쩡합니다.** 지금까지 쓰던 길로
  갈 뿐이고, 그 길에도 7초 제한·한 번 재시도·실패 안내가
  들어가 있습니다. 다만 그때부터 **다시 느려질 수 있습니다.**

---

## 3. 되돌리는 법 (감독실 FileZilla)

### 올리기 **전에** 반드시

운영 `/assets/tide/` 폴더를 통째로 내려받아 날짜 폴더에 둡니다.

```
C:\prod-backup-20261013\물때_YYYYMMDD\assets\tide\   ← 57개
```

**되돌릴 것이 없으면 되돌리기도 없습니다.**

### 되돌리는 차례

1. 받아 둔 폴더의 57개를 운영 `/assets/tide/` 로 **덮어씁니다**
2. `python -m engine.check_tide_live` 로 확인합니다
3. 그래도 이상하면 **운영 `/assets/tide/` 폴더를 통째로 지웁니다**

★ 3번이 안전한 까닭: 파일이 없으면 화면이 **지금까지 쓰던 길**로
  갑니다(`api/tide-cache.php`). 느려질 뿐 **고장나지 않습니다.**
  첫 갱신이라 되돌릴 옛 파일이 없을 때도 마찬가지입니다 —
  **지우기만 하면 원래대로**입니다.

---

## 4. 이상이 나면 어디를 보나

| 증상 | 먼저 볼 것 |
|---|---|
| 물때가 안 나옴 | `check_tide_live` — 404 인지 폴백인지 |
| 시각이 이상함 | `check_tide_files` — 겹치는 날 값이 달라졌는지 |
| 갑자기 느려짐 | 남은 날이 7일 미만이라 폴백 중인지 |
| 빈 날이 많음 | 다시 받으면 **합치기**로 채워집니다 |

★ **값이 이상하다**는 신고가 오면 그 파일을 먼저 지우십시오.
  지우면 정부 API 로 돌아가 **맞는 값**이 나옵니다. 원인은
  그다음에 찾습니다.

---

## 5. 왜 이렇게 만들었나 (까닭 기록)

- 간조·만조는 **천문 계산값**이라 변하지 않습니다. 그래서 미리
  받아 둘 수 있습니다.
- 정부 API 는 건강할 때 **70ms** 인데 **간헐적으로 응답이
  없습니다** — 같은 주소가 1.97초였다 133초였다 합니다.
  손님이 그걸 그대로 맞아 **32초**를 기다린 적이 있습니다.
- 받을 때마다 **다른 날이 빕니다.** 그래서 「다 찬 것만 저장」이
  아니라 **합치기**로 모읍니다. 한 번만 성공하면 그 날은 끝입니다.
  이 방식은 **절대 나빠지지 않습니다** — 새로 받은 것이 비어도
  옛 값을 지우지 않습니다.
- 화면은 파일의 **날짜를 보고 오늘 이전을 잘라냅니다.** 순서로
  꺼내면 만든 날이 「오늘」이 되어 **지난 물때를 보여 주기**
  때문입니다. 이 결함은 2026-10-14 올리기 직전에 감사팀이
  찾아냈습니다.
- `/data/` 는 서버가 막습니다(403). 손님이 읽을 파일은
  **`/assets/` 아래**에 둡니다.
