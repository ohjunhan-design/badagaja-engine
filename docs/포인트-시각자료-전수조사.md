### 같은 점을 쓰는 곳 693 (19.7%)

지도에 그리면 **핀이 겹쳐 하나로 보입니다.** 자리가 여덟인데
점이 하나면 「여덟 곳」을 보여 줄 수 없습니다.

### 이웃이 멀리 떨어진 곳 — 1개뿐입니다

```

```

**백도**입니다 — 여수에서 멀리 떨어진 섬이라 **맞는 좌표**입니다.
지형이 「⚠️ 현장 판단 필요」이기도 합니다.

### 그래서 — 「지도 제작 가능」은 이렇게 가립니다

| | 곳 | |
|---|---|---|
| 좌표 없음 | 89 | **지도 못 그림** |
| 좌표가 거침(3자리 이하) | 66 | **지도 못 그림** |

> 다만 **「그릴 수 있다」가 「그려도 맞다」는 아닙니다.**
> 좌표가 바다인지 육지인지, 들어가는 길이 맞는지는
> **사람이 봐야 압니다**(기억: 좌표는 주소로 되짚어 봅니다 ·
> 위성사진을 눈으로 보면 섬을 육지라 합니다).
