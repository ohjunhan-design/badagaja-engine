# 아이디어뱅크 — 보관만 합니다. 지금 만들지 않습니다.

2026-10-09 주인 지시(지피티를 거쳐 전달).

> 「아이디어뱅크를 실제 PC 프로젝트에 만들어 주세요. 단,
>  아이디어 보관만 하고 지금 구현하지 마세요.」

**여기 적힌 것은 코드로 옮기지 않습니다.** 주인이 「이것을
하자」고 하실 때까지 기다립니다. 생각이 사라지지 않게 적어
두는 자리입니다.

적을 때는 이렇게 씁니다 —
**무엇을 · 왜 · 걸리는 것 · 지금 안 하는 까닭 · 하려면 무엇이 먼저**

## 01. 지도·장소를 네이버로 옮기거나 함께 쓰기

| | |
|---|---|
| 상태 | **보류** — 확정 아님 |
| 받은 날 | 2026-10-09 |

**무엇을** 지금 지도·장소 기능이 카카오 중심입니다.
이것을 네이버로 옮기거나, 둘을 함께 쓰는 방안입니다.

**왜** 국내 검색·장소 정보에서 네이버 쪽이 자료가 넓습니다.

**걸리는 것**
- 좌표 3,603곳이 모두 지금 지도에 맞춰져 있습니다
- 지도를 바꾸면 쪽 수백 개가 함께 흔들립니다
- 두 곳을 함께 쓰면 **같은 사실이 두 곳에 생깁니다** —
  언젠가 반드시 어긋납니다(이 저장소가 가장 경계하는 것)

**지금 의견** 지피티 전달: 「전면 네이버 전환으로 확정된 것이
아닙니다. **카카오 지도 유지 + 네이버 업체 탐색 보조**가
안전해 보인다는 수준입니다. 구현 금지입니다.」

**하려면 무엇이 먼저**
1. 지금 지도를 쓰는 자리를 전수로 셉니다
2. 네이버 쪽 무료 한도와 조건을 확인합니다
3. 한 권역만 시범으로 바꿔 견줍니다

## 02. 권역별 낚시용품점 안내

| | |
|---|---|
| 상태 | **보류** — 구현 금지 |
| 받은 날 | 2026-10-09 |

**무엇을** 권역마다 가까운 낚시용품점의 주소·전화·영업시간을
안내합니다.

**왜** 채비를 보고 나면 「어디서 사나」가 바로 다음 물음입니다.
지금은 「낚시점에서 물어보세요」로 끝납니다.

**걸리는 것**
- **업체 수를 지어내면 안 됩니다**(주인 지시). 센 것만 적습니다
- 영업시간·전화는 자주 바뀝니다 — 갱신 대장(규칙 30)에
  올려야 합니다
- 바깥 자료를 불러오면 **돈이 듭니다**

**과금을 막는 방법** (함께 받은 아이디어)
- 무료 한도 안에서만 부릅니다
- 받아 온 것을 쌓아 둡니다(캐시)
- 한 곳씩이 아니라 **몰아서** 받습니다(배치)

**하려면 무엇이 먼저**
1. 어느 자료에서 받을지 정합니다(공공 자료가 있는지 먼저)
2. 한 권역으로 시범 — 몇 곳이 나오는지, 믿을 만한지
3. 갱신을 누가 언제 하는지 정합니다
