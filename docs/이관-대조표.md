## 먼저 알아 둘 것

운영 **badagaja.com** 은 **엔진 저장소**(`D:\바다가자\두번째도전`)가 만듭니다.
옛 저장소(`D:\바다가자\badagaja-site`)는 **멈춘 저장소**입니다.

```
  옛 저장소에서 고치면          엔진에서 고치면
  ───────────────────          ───────────────
  운영에 안 올라갑니다          다음 배포에 올라갑니다
  (자동 배포가 막혀 있음)        그리고 **안 덮입니다**
  손으로 올려도 다음
  엔진 배포에 덮입니다
```

2026-10-12 오전, 주인께서 옛 저장소에서 고치신 것이 오후에 통째로
덮였습니다. 이 표는 그런 일을 막으려고 만듭니다.

---

## 쪽 하나를 고치고 싶을 때

**옛 저장소에서 그 쪽 HTML 을 찾지 마십시오.** 엔진에서는 쪽이
**자료 + 틀 + 생성기** 셋으로 만들어집니다.

```
  data/raw/*.json  ──┐
                     ├──▶  engine/*.py  ──▶  template/*.html  ──▶  site/*.html
  (적는 값)          │      (짜는 법)         (생긴 꼴)          (나온 쪽)
                     │                                           ↑ 손대지 마십시오
                     │                                             다음 빌드에 사라집니다
```

**`site/` 아래는 모두 생성물입니다.** 거기를 고치면 다음 빌드에 없어집니다.

## 대조표

### 모든 쪽에 걸리는 것

| 고치고 싶은 것 | 엔진에서 여기 |
|---|---|
| 머리 로고 | `engine/build.py` 의 `LOGO_SVG` |
| 꼬리 로고 | `engine/build.py` 의 `LOGO_BIG` |
| 머리띠 돋보기·테두리 | `assets/css/site.css` 의 `.brand` 무리 |
| 꼬리 메뉴 항목 | `data/raw/site.json` 의 `꼬리메뉴` ★ 틀에 박지 않습니다 |
| 운영책임자·연락처 | `data/raw/site.json` 의 `운영책임자` |
| 머리·꼬리 생김새 | `template/_header.html` · `template/_footer.html` |
| `<head>` 안의 것 | `template/_head.html` |
| 판 지문·갱신 날짜 | `engine/template.py` 의 `지금판()` — 손대지 않습니다 |

★ **단계 쪽만 다릅니다.** 틀을 채우지 않고 **통째로 복사**합니다.
그래서 거기만 `{{ }}` 가 없고, 판 지문도 따로 새겨 넣습니다
(`template.손쪽에판새기기()`). 이런 쪽을 더 만들 때는 **반드시**
그 함수를 지나가게 하십시오 — 안 그러면 검사기 눈 밖에 납니다.

**사이트에 적는 숫자는 손으로 적지 않습니다.** 자료에서 셉니다.

`묶음`·`관광안내`·`물때관측소` 같은 값이 권역마다 붙어 있습니다.

## 고친 뒤 할 일

```bash
python engine/build.py       # 쪽을 다시 만듭니다
python engine/build_id.py    # 판 지문을 새깁니다
```

그다음 빠른 검사를 돌립니다.

```bash
python engine/check_links.py
python engine/check_build_stamp.py
python engine/check_numbers.py
python engine/check_contracts.py
```

배포는 **깃허브에서 손으로** 겁니다. 판정을 반드시 거치며 우회로가
없습니다.

```bash
gh workflow run deploy.yml --ref main -f confirm=배포합니다
```

## 겪은 일에서 나온 주의

| 함정 | 어떻게 피하나 |
|---|---|
| `site/` 를 손으로 고침 | 다음 빌드에 사라집니다. **생성기를 고치십시오** |
| 자료 json 을 다시 써서 저장 | 들여쓰기가 통째로 바뀌고 **중복 키 하나가 조용히 사라집니다**. 글 그대로 한 줄만 끼우십시오 |
| 자료 파일이 CRLF | `site.json`·`hubs_more.py` 는 CRLF 입니다. `\n` 으로 찾으면 **조용히 실패**합니다 |
| 로컬만 보고 판단 | 옛 저장소는 로컬이 낡아 있을 수 있습니다. **원격**(`origin/main`)을 보십시오 |
| 차림표 이름을 새로 지음 | 정의가 없으면 **아무 일도 안 일어납니다**. `site.css` 에 있는지 먼저 세어 보십시오 |
