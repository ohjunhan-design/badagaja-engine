지금 제목이 **61자**이고 「동호회」·「지원」이 **각각 두 번** 나옵니다.
주인 규칙 28 — 「제목에 같은 말을 2회 이상 되풀이하지 않습니다
(반복 키워드는 불이익)」에 걸립니다.

```
우리 동호회 이름 그대로, 활동 공간은 바다가자가 지원합니다
 — 전국 낚시·해루질 동호회 지원 | 바다가자닷컴
```

까닭은 `큰제목` 과 `한줄`(「전국 낚시·해루질 동호회 지원」)을 이어
붙이는데 **둘 다 그 말을 품고** 있어서입니다. `site.json` 300줄에
이미 「앞서 둘 다 같은 말이 두 번 나왔습니다」라는 기록이 있는데,
머리띠·배지는 고쳐졌고 **`<title>` 만 남았습니다.**

후보 (기록만 해 둡니다 — 쓰지 않았습니다)

```
우리 이름 그대로 쓰는 낚시·해루질 모임 공간 | 바다가자닷컴   (31자)
```

## 2. 범위가 커서 미뤄 둔 것 (할 일로만 올림)

### ㉠ og 사진이 여러 쪽에 겹침 — **72쪽**
주인 규칙 28 — 「og:image 는 **쪽마다 다른 사진**이어야 합니다」

```
hero.jpg           9쪽
aewol-hero.jpg     3쪽
boryeong-hero.jpg  3쪽
buan-hero.jpg      3쪽   … 그 밖 66쪽
```

권역 하나에 **낚시·해루질·축제** 쪽이 있어 같은 대표 사진을 함께
쓰기 때문으로 보입니다. 고치려면 **사진을 더 구해야 할 수도**
있어 범위가 큽니다. 무인 중에는 손대지 않습니다.

먼저 가릴 것 — 「쪽마다 달라야 한다」를 **어디까지** 적용할지.
권역 안에서 갈래별로 다른 사진을 쓸 만큼 사진이 있는지부터
세어야 합니다.

### ㉡ 구조화 자료(JSON-LD) 없음 — **16쪽**
```
about · catch/basics · catch/gear · data · fish/basics · gear … 16쪽
```
안내 쪽들입니다. 어떤 유형(`Article`·`FAQPage`·`HowTo`)을 쓸지
먼저 정해야 합니다. 규칙 28 — 짐작하지 말고 가이드를 보고 정합니다.
