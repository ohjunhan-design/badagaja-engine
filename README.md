# 바다가자닷컴 — 두 번째 도전

전국 바다의 **물때 · 낚시 포인트 · 해루질 자리**를 한곳에 모은 사이트입니다.
<https://badagaja.com>

---

## ★ 처음 보신다면 — 여기가 어디인지 먼저

이 저장소에는 **두 벌의 사이트**가 들어 있습니다. 헷갈리기 쉬우니 먼저 밝힙니다.

| 폴더 | 무엇인가 | 봐야 하나 |
|---|---|---|
| **`site/`** | **지금 서비스하는 사이트** (생성물) | **네. 이것이 지금입니다** |
| `oldsite/` | **옛 사이트 사본** — 첫 번째 도전 | 아니요. 참고·대조용입니다 |
| `engine/` | 쪽을 만드는 생성기와 검사기 | 고칠 때는 여기를 고칩니다 |
| `data/` | 자료 (쪽은 여기서 만들어집니다) | |
| `template/` | 쪽 겉틀 | |

> **`oldsite/` 를 보고 판단하지 마십시오.** 그것은 옛 판입니다.
> 새 사이트에서 이미 고쳐진 것이 거기에는 옛 모습으로 남아 있습니다.

---

## ★ 지금 어느 판인가 — 짐작하지 말고 확인하는 법

공개 사이트의 어느 쪽에서든 **세 가지로 확인**할 수 있습니다.

| 어디서 | 무엇이 보이나 |
|---|---|
| 쪽 맨 아래 | `사이트 업데이트 2026.10.07` |
| HTML 머리 | `<meta name="badagaja-build" content="400c262">` |
| <https://badagaja.com/build.json> | 커밋·파일 수·지문까지 전부 |

```bash
curl -s https://badagaja.com/build.json | head -20
```

**「기준일 26년 9월」 같은 글로 최신 여부를 판단하지 마십시오.**
그것은 **자료의 기준 시점**이지 사이트의 판이 아닙니다.
자료가 9월 것이면 9월이라 적는 것이 정직한 표시입니다.

`engine/check_build_stamp.py` 가 **모든 쪽이 같은 판을 밝히는지** 봅니다.
값이 갈리면 배포가 섞인 것이라 판정이 막습니다.

## 만들고 올리는 법

```bash
python engine/build.py          # site/ 를 다시 만듭니다
python engine/gate.py --full    # 판정 (검사기 40여 가지)
```

올리는 것은 깃허브 액션이 합니다 — `main` 에 올린 뒤
Actions → **운영 배포** → 입력칸에 `배포합니다`.

- 판정이 GO 가 아니면 **멈춥니다**
- 올리기 전에 **서버를 통째로 백업**합니다
- 올린 뒤 검사가 나쁘면 **스스로 되돌립니다**

## 손대면 안 되는 것

| 무엇 | 왜 |
|---|---|
| `api/` | 물때·장소 캐시. 지우면 **전국 물때가 죽습니다** |
| `.htaccess` | 한 번에 한 가지만. **BOM 이 붙으면 사이트가 500 으로 멈춥니다** |
| `zh-cn/` · `zh-tw/` | 중국어판 190쪽. 그대로 두기로 했습니다 |
| 네이버·구글 인증 파일 | 지우면 **검색 등록이 풀립니다** |

자세한 것은 `data/raw/keep.json` 과 `docs/CONTRACTS.md` 를 보십시오.

## 규칙

작업 규칙은 `CLAUDE.md` 에 있습니다. 가장 중요한 것 몇 가지 —

- **숫자는 자료에서 셉니다.** 손으로 적지 않습니다
- **쪽을 고쳤으면 생성기도 고칩니다.** 안 그러면 다시 만들 때 되돌아갑니다
- **새 검사는 잡은 뒤에 만듭니다.** 놓친 잘못을 찾으면 검사기에 더합니다
- **근거 자료(`data-private/`)는 웹에 내지 않습니다**
