# ⚠ 여기는 **옛 사이트**입니다 — 첫 번째 도전

**이 폴더를 보고 사이트를 판단하지 마십시오.**

여기 있는 쪽들은 **옛 판**입니다. 지금 서비스하는 것은 `../site/` 입니다.

---

## 왜 남겨 두었나

지우지 않고 두는 데는 까닭이 있습니다.

| 쓰임 | 어느 검사기가 |
|---|---|
| 옛 주소가 새 사이트에서 길을 잃지 않았는지 | `engine/check_urls.py` |
| 옛 쪽이 가졌던 것을 새 쪽이 잃지 않았는지 | `engine/check_design.py` |
| 옛 물때 계산과 새 계산이 같은 답을 내는지 | `engine/check_tide_old.py` |
| 중국어판 190쪽이 거는 파일을 지우지 않도록 | `data/raw/keep.json` |

이 안전망이 없으면, 서버를 정리하다 **중국어판이 통째로 깨지거나**
옛 주소가 404 가 됩니다. 실제로 2026-10-07 에 그럴 뻔했습니다.

## 여기서 겪은 일 (2026-10-07)

서버를 정리하려고 **이 폴더를 기준으로** 지울 목록을 만들었습니다.
처음에 **323개**를 지우려 했습니다. 바깥 검수를 네 번 거치며 —

```
323개  →  102  →  24  →  5  →  4  →  2개
```

로 줄었고, 그 과정에서 이 폴더가 **서버 실물의 38% 밖에 안 된다**는
것을 알았습니다. 서버에는 **1,979개**가 있었고, 그 가운데 767개는
여기에도 `../site/` 에도 없는 것이었습니다 (`api/` 캐시 676개,
네이버 인증 파일, PWA 아이콘 …).

**이 사본으로 서버를 짐작하면 안 됩니다.**
서버를 알아야 할 때는 배포가 남기는 「배포전-서버」 백업을 받으십시오.
