# 공유 미리보기 그림이 들어오는 자리입니다

여기에 그림을 넣으면 **코드를 한 줄도 안 고치고** 그 쪽의
공유 미리보기가 바뀝니다.

    assets/og/rig/metal.webp      → site/rig/metal.html 의 og:image
    assets/og/어종/ureok.webp      → site/fish/ureok.html
    assets/og/해루질/nakji.webp     → site/catch/nakji.html

`.webp` · `.jpg` · `.png` 차례로 찾습니다. 없으면 지금까지 쓰던
사진이 그대로 쓰입니다 — **빈 자리가 생기지 않습니다.**

## 규격

1200 x 630. 가로세로 비가 3:1 을 넘으면 안 되고 150x150 보다
커야 합니다 (네이버·구글 가이드).
